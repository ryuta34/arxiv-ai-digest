# ROWBench: Do Video Models Render What the Program Specifies?

| 項目 | 内容 |
|---|---|
| どんなもの？ | プログラム可能なワールドモデルの視覚的忠実度を評価するためのベンチマーク「PROWBench」の提案。170の動的エピソードと600の同期されたプロキシビデオを用い、生成された動画がプログラムの指示（論理、タイミング、相互作用）にどれだけ正確に従っているかを評価する。 |
| 先行研究と比べてどこがすごい？ | 従来のベンチマークは視覚品質や一般的な指示遵守に焦点を当てていたが、本研究はエンジン記録に基づき、隠れた状態や長期的なイベントを網羅した「fine-grained（細粒度）」なプログラムイベントとの整合性をテストできる点。 |
| 技術や手法のキモはどこ？ | プログラムの実行結果（状態、アクション、タイムスタンプ）を、「Coarse 3D」「CWMプロキシ」「Colored-OBB」という3種類の同期された視覚的表現に変換し、生成動画と ground-truth を直接比較できるようにした点。また、VLMを用いた「Logic-Render Alignment」と「Interaction Success Rate」という新しい指標の導入。 |
| どうやって有効だと検証した？ | 主要な動画生成モデル（MiniMax-H3, Seedance 2.5, CWM等）を対象に、ショートクリップのメイントラックと、長期記憶・マルチビューを評価するチャレンジトラックの両面で実験。プロキシ条件付けモデルがカメラ条件付けモデルよりも優れた軌道追従性を示すことを定量的に検証した。 |
| 議論はある？ | 視覚的なもっともらしさは、プログラムの忠実な実行を保証しないこと。特に視覚的参照がない場合、個人の外見（ID）や向きの制御が不正確になりがちである。また、汎用的なビデオ生成モデルは、空間的な配置は良好でも、特定のイベント実行（銃撃等の複雑な相互作用）において専門モデルに劣る場合がある。 |
