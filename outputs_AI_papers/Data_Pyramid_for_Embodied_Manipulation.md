# Data Pyramid for Embodied Manipulation

| 項目 | 内容 |
|---|---|
| どんなもの？ |  Embodied AI（身体化AI）における多様なデータソースを「データピラミッド」として体系化し、ロボット学習モデルにおけるデータ活用の指針を示す調査論文です。リアルロボット、UMI、エゴセントリック、シミュレーション、汎用データの5つのソースを、スケーラビリティとロボット適応性の観点から分類しています。 |
| 先行研究と比べてどこがすごい？ | 個別のモデルや手法に焦点を当てた既存のサーベイとは異なり、データ駆動型の視点から、異種混合データの収集・整理・統合という体系的な分類法を提供した点です。データ品質や多様性、転用可能性といった6つの指標を用いて、各データソースの特性を包括的に分析しています。 |
| 技術や手法のキモはどこ？ | スケーラビリティ（拡張の容易さ）とロボット適応性（実機での学習への直接性）という二軸による「データピラミッド」の定義です。頂点に近いデータほど実機適応性が高く、ベースに近いデータほどスケーラビリティが高いという構造化により、データレシピ（混合戦略）を設計するフレームワークを構築しました。 |
| どうやって有効だと検証した？ | 過去10年間の主要なロボット学習データセットを収集・整理し、年代ごとの成長トレンドを可視化しました。また、代表的なembodied foundation model（VLA、WAMなど）の学習におけるデータレシピの変遷を分析することで、ヘテロジニアスなデータミックスが性能向上に寄与している実証的根拠を提示しています。 |
| 議論はある？ | 現在のデータレシピは試行錯誤的なものが多く、最適なデータ構成比率が未解明である点を挙げています。また、物理的な接地性の欠如（特に汎用データ）、sim-to-realギャップ、身体性の不一致といった課題が依然として残っており、これらを解決するためのデータフィルタリングやアライメント手法の確立が今後の焦点です。 |
