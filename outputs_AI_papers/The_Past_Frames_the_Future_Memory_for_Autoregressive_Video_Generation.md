# The Past Frames the Future: Memory for Autoregressive Video Generation

| 項目 | 内容 |
|---|---|
| どんなもの？ | 自回帰（AR）型ビデオ生成における「メモリメカニズム」を体系的に整理・分類した包括的なサーベイ論文です。長期一貫性のあるビデオ生成において、限られたコンテキストウィンドウ内で過去の情報をいかに保持・活用するかという課題を構造化し、現状の技術を分類しています。 |
| 先行研究と比べてどこがすごい？ | 既存のサーベイが特定の生成手法（拡散モデル等）やワールドモデルに限定されていたのに対し、メモリに焦点を当てて統一的なフレームワーク（Forms, Functions, Operations, Learning, Evaluation）を構築した点です。断片化されていたメモリ概念を整理し、比較・分析を容易にした点が優れています。 |
| 技術や手法のキモはどこ？ | メモリのライフサイクルを5つのコア操作（書き込み、読み出し、更新、管理、統合）として定義し、メモリの種類を「視覚（Visual）」「暗黙的状態（Implicit State）」「明示的状態（Explicit State）」「適応型パラメトリック（Adaptive Parametric）」の4形態に分類した点です。 |
| どうやって有効だと検証した？ | 既存の数百にも及ぶ研究を、提案した5つの軸と各メモリの形態（キャリヤー）に基づいて分類し、各手法の特性（計算量、解釈性、モデル結合度など）を比較整理するメタ分析を行っています。また、メモリの有効性を評価するためのプロトコル（情報ギャップの作成など）の重要性を説いています。 |
| 議論はある？ | 汎用的なメモリ設計の欠如、動的更新時の信頼性、リソース制約下での効率的な圧縮、およびメモリ評価のための標準化されたベンチマークの不足が挙げられます。特に、「メモリが意図した通りに機能しているか（因果関係の分離）」を検証する指標の確立が最大の課題です。 |
| 次に読むべき論文は？ | [130] Self forcing, [347] Longlive, [410] Causal forcing, [413] Memorize-and-generate などのメモリ効率と長期安定性を両立させる基盤研究。 |
