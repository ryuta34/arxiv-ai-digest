# From Pixels to States: Rethinking Interactive World Models as Game Engines

| 項目 | 内容 |
|---|---|
| どんなもの？ | 従来のゲームエンジンが持つ「アクション・状態・観察」の再帰的なループ構造をレンズとして、インタラクティブな世界モデルを4つの次元で再定義・整理した研究。また、AAAタイトル『Black Myth: Wukong』を用いた90時間超の高品質なデータセットおよびデータ構築パイプラインを提案している。 |
| 先行研究と比べてどこがすごい？ | 既存のビデオ生成モデルや世界モデルを単なる「次フレーム予測」として捉えるのではなく、ゲームエンジンとしての役割という観点から体系的に分類・整理した点。また、大規模な商用ゲームタイトルからフレームアライメントされたゲーム状態データを含む実用的なリソースを提供した点。 |
| 技術や手法のキモはどこ？ | インタラクティブな世界モデルを「①プレイヤーアクションの制御」「②ゲーム状態のダイナミクス」「③状態と観察の永続性」「④リアルタイム生成」の4次元で構造化したフレームワーク。さらに、リプレイデータからJSON形式の構造化アクション・状態ログと、Qwen3-VL-235Bを用いて生成した「スロット構造化キャプション」と「意味論的キャプション」を組み合わせた精緻なデータセット構築手法。 |
| どうやって有効だと検証した？ | 既存研究の網羅的なサーベイと分析を通じて本フレームワークの妥当性を示し、Black Myth: Wukongのプレイ動画を用いたデータ収集パイプラインを構築することで、既存データセットの希少性（ゲーム状態の欠如）を克服するリソースを提供した。 |
| 議論はある？ | 明示的なゲーム状態を生成ループに統合することの難しさ、メモリ更新を状態遷移にどのように接地させるか、およびアクションのタイミングとゲームルールの整合性をどう取るかという点が今後の主要な課題として挙げられている。 |
