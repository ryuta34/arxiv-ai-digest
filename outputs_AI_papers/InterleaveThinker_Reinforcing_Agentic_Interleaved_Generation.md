# InterleaveThinker: Reinforcing Agentic Interleaved Generation

| 項目 | 内容 |
|---|---|
| どんなもの？ | 既存の画像生成モデルに「インターリーブ生成（テキストと画像の順序立った系列生成）」能力を付与する、マルチエージェント型の汎用フレームワーク。PlannerとCriticを用いたパイプラインにより、長期間の生成における視覚的な過学習や誤差の蓄積を解決する。 |
| 先行研究と比べてどこがすごい？ | 従来の統一マルチモーダルモデル（UMM）が抱える「視覚的過学習」と「逐次的な誤差蓄積」を、計画と実行を分離することで根本的に回避した点。また、モデルを学習し直すことなく、既存の固定画像生成モデルをインターリーブ生成に対応させられる汎用性がある。 |
| 技術や手法のキモはどこ？ | Plannerが全ステップの指示を事前に立案して視覚フィードバックの依存を断ち切る設計と、Criticが生成プロセスを監視・修正する反復的な自己訂正メカニズム。さらに、効率的な学習のため、長大な軌跡をステップごとの単一アクションに分解し、二重報酬戦略による効率的な強化学習を導入したこと。 |
| どうやって有効だと検証した？ | インターリーブ生成ベンチマーク（UEval, CoMM）および推論ベンチマーク（WISE, RISE）を用いて検証。FLUX.2-klein等の既存モデルと統合し、オープンソースのUMMを大幅に上回る性能を実証したほか、推論ベースのタスクでもベースモデルの性能を大幅に向上させた。 |
| 議論はある？ | フレームワーク自体の能力は、ベースとなる画像生成モデルの生成可能な概念知識に依存するため、学習データに含まれない未知の概念を生成できないという限界がある（Appendixの図8で失敗例を提示）。 |
