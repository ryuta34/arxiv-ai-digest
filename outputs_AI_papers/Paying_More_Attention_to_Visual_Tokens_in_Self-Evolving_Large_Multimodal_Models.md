# Paying More Attention to Visual Tokens in Self-Evolving Large Multimodal Models

| 項目 | 内容 |
|---|---|
| どんなもの？ | 大規模マルチモーダルモデル（LMM）において、言語モデルの事前知識に依存しすぎて画像内容を無視する「視覚的過小条件付け（visual under-conditioning）」を解決するための、完全に教師なしの自己進化フレームワークVISE。 |
| 先行研究と比べてどこがすごい？ | 既存研究が回答の合意（答えが同じかどうか）のみを最適化するのに対し、VISEはモデルの視覚条件付けポリシーを直接正則化する。これにより、外部の報酬モデルや人間によるアノテーションなしで、キャプショニングやVQA、ハルシネーション抑制において従来手法を一貫して上回る性能を達成した。 |
| 技術や手法のキモはどこ？ | 「幾何学的不変性報酬（空間的整合性の強制）」と「意味的不変性報酬（領域摂動を用いた根拠感度の強化）」という2つの不変性報酬を組み合わせて最適化する点。単一モデル内で、モデル自身の推論結果のみを用いて学習を行う。 |
| どうやって有効だと検証した？ | Qwen3-VLシリーズ（2B〜32B）の4つのモデル規模と4つのバックボーンアーキテクチャを用い、計18のベンチマーク（画像キャプショニング、VQA、推論、ハルシネーション評価）で比較実験を実施し、ベースラインと比較して大幅な精度向上とハルシネーションの低減を確認した。 |
| 議論はある？ | モデル規模が大きくなるにつれて向上幅は鈍化する傾向にある（事前学習ですでに視覚条件付けが強化されているため）。また、推論時に追加のforward passが必要となる計算コストについても触れられている。 |
