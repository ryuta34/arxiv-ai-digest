# GameHorizon Suite: Multi-Horizon Data and Evaluation in Gameplay

| 項目 | 内容 |
|---|---|
| どんなもの？ | 現代のAAAゲームを対象に、視覚理解・計画・操作能力を多角的に測定する大規模なデータセットおよび評価ベンチマーク「GameHorizon Suite」です。短時間操作・中期的目標・長期的戦略の3階層でマルチホライゾンな指示を構築し、モデルの性能を総合的に評価します。 |
| 先行研究と比べてどこがすごい？ | 5,000時間もの大規模AAAゲームのデータを使用し、人間による実際の操作ログと密なマルチホライゾン命令を統合している点です。また、再現性の高いオフラインベンチマークと、エラー診断が可能なステップ実行型のオンライン評価を両立させています。 |
| 技術や手法のキモはどこ？ | VLMを用いたボトムアップ形式のアノテーションパイプラインにより、細かい操作ログから自動的に高次の戦略へ抽象化を行う手法を採用した点です。また、ゲーム環境に応じた動的なキーバインド定義により、汎用的な性能評価を可能にしました。 |
| どうやって有効だと検証した？ | 47種類のAIモデルに対してオフラインで5,000件以上の多肢選択問題（MCQ）を用いた評価を行い、オンライン trackでは12モデルに対しMinecraft環境で20の長期的タスクを課して性能を比較しました。オフラインスコアと実機性能に正の相関があることを確認しています。 |
| 議論はある？ | 軽量なモデルでは「思考」プロセスを導入すると幻覚（ハルシネーション）による性能劣化が見られることや、長期的計画におけるモデルのボトルネックが明確になりました。また、環境設定のコストがオンライン評価の制約となっています。 |
