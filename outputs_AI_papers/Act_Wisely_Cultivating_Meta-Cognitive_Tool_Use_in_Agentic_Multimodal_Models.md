# Act Wisely: Cultivating Meta-Cognitive Tool Use in Agentic Multimodal Models

| 項目 | 内容 |
|---|---|
| どんなもの？ | エージェント型マルチモーダルモデルにおける「盲目的なツール使用」という欠陥を克服し、必要な時だけツールを適切に使用できるように学習させる新しい強化学習フレームワーク「HDPO」と、それを適用したモデル「Metis」。 |
| 先行研究と比べてどこがすごい？ | 従来の強化学習はツール使用の効率性とタスクの正確性を単一の報酬に統合（スカラー化）していたため、一方を優先すると他方が犠牲になるというジレンマがあった。本手法はこれらを独立した最適化チャネルに分離することで、効率性と精度の両立を実現し、ツール使用を90%以上削減しつつ推論精度を向上させた点。 |
| 技術や手法のキモはどこ？ | 報酬を統合せず、「正確性チャネル」と「効率性チャネル」に分離し、効率性の報酬を「正解した軌跡のみ」に条件付けて最適化する「階層的デカップリング方針最適化（HDPO）」。これにより、まずは正確な推論を習得し、次に効率化を学ぶという自然な認知カリキュラムが構築される。 |
| どうやって有効だと検証した？ | V*Bench、HRBench、CharXiv、MathVista等の複数のベンチマークにおいて、既存のオープンソースモデルやエージェントモデルと比較評価を実施。また、消去法（アブレーション）分析を行い、デカップリングによる精度の向上とツール使用の抑制効果を定量的・定性的に証明した。 |
| 議論はある？ | 現在は「ツールを使わない」という消極的選択を学習させているが、今後はより長期的でオープンエンドな環境において、より高度で複雑な意思決定プロセスのメタ認知能力をどう拡張するかが課題。 |
