# SynCity 3000: Bootstrapping Scene-Scale 3D Diffusion

| 項目 | 内容 |
|---|---|
| どんなもの？ | 大規模で複雑な3Dシーンをテキストプロンプトから生成するフレームワーク。2段階の生成プロセスにより、従来のタイルベース生成で見られたグリッド構造の違和感を排除し、一貫性のある3D世界を生成する。 |
| 先行研究と比べてどこがすごい？ | 既存のタイルベース手法（SynCity等）で不可避だったグリッド状の断片化を解消した。また、物体中心の生成モデルをシーン全体に適用できるよう適応させることで、複雑かつ大規模なシーンを細部まで忠実に生成可能である点。 |
| 技術や手法のキモはどこ？ | 第一段階で重なり合うウィンドウを用いた拡散モデルでグローバルに一貫した2Dテンプレートを生成し、第二段階で3D生成モデル（TRELLIS）を「畳み込み的（convolutional）」に動作させるよう再学習・最適化した点。 |
| どうやって有効だと検証した？ | 提案したデータセット生成エンジンによる定量的評価（Chamfer距離、F-score、LPIPS、PSNR等）に加え、ユーザー評価による比較（レイアウト制御や忠実度等）を実施し、従来手法を凌駕することを示した。 |
| 議論はある？ | 現在の生成物がトレーニングデータ（Objaverse-XL）由来の「漫画的な外観」になりがちである点、および計算コストがシーンサイズに対して二次関数的に増大する点が課題。また、特定の投影（dimetric）に依存した構成となっている。 |
