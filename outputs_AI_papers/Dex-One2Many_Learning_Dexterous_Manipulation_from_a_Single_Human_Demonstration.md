# Dex-One2Many: Learning Dexterous Manipulation from a Single Human Demonstration

| 項目 | 内容 |
|---|---|
| どんなもの？ | 1つの人間によるデモンストレーション動画から、ロボットの器用な操作スキルを習得するフレームワーク。動画からタスクの構造（関係性）のみを抽出し、それに基づいた強化学習を行うことで、現実環境で多様な初期配置や対象物に対応したゼロショット転移を可能にする。 |
| 先行研究と比べてどこがすごい？ | 従来の模倣学習が動画の「具体的な動き」を再現しようとして配置の変化に弱かったのに対し、本手法は動画から「タスクの関係性（シーングラフ）」のみを抽象化して抽出するため、動画にない未知の初期・目標配置に対しても高い汎用性と成功率（最大71%の改善）を実現した点。 |
| 技術や手法のキモはどこ？ | VLM（ビジョン言語モデル）を用いた動画からの「ステージ別シーングラフ」抽出と、それを制約条件とした強化学習（Reset-based RL）。各ステージのグラフをリセット分布および報酬として活用することで、効率的な探索とタスク構造の学習を両立させたこと。 |
| どうやって有効だと検証した？ | 5つの操作タスク（人形、缶、スタンプ、ハンマー、スイープ）を用い、シミュレーションおよびUR3ロボットと20自由度の手を用いた現実環境で検証。動画と異なる初期・目標位置における成功率をベースライン手法と比較し、大幅な優位性を実証した。 |
| 議論はある？ | 現在の実装では剛体のみを扱っているため、変形物体や関節物体の操作には手動の事前準備が必要な点。また、現実環境での性能が物体姿勢推定の精度に依存しており、ノイズや遮蔽による性能低下が課題として挙げられている。 |
