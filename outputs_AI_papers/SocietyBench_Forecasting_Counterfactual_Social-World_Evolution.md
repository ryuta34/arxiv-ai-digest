# SocietyBench: Forecasting Counterfactual Social-World Evolution

| 項目 | 内容 |
|---|---|
| どんなもの？ | 現実の社会的な出来事の展開を予測する能力を測定するための、エンドツーエンドのベンチマーク「SocietyBench」。LLMが特定の出来事の記憶に頼らず、因果関係や時間的な推論に基づいて将来を予測できるかを評価する。 |
| 先行研究と比べてどこがすごい？ | 従来のベンチマークがタスク完了（プログラミング等）やシミュレーションに偏る中、本研究は現実のニュースと世論の変化を統合した「社会的な出来事の予測」に焦点を当てた点。また、記憶による過学習を防ぐ「反実仮想的」な評価プロトコルを導入した点。 |
| 技術や手法のキモはどこ？ | ニュースやSNSから抽出したタイムラインに対し、固有名詞の置換と日付のランダムシフトを行うことで、元の出来事を特定できない「反実仮想的な社会世界」を構築する点。また、確率的予測（キャリブレーション）と時間的予測（日付）の2軸で厳密にスコアリングする点。 |
| どうやって有効だと検証した？ | 5つの異なる領域（紛争、経済等）の社会的事象を用い、6つの主要なLLM（GPT-5.5等）と3つのエージェントフレームワークを評価。LLMの予測精度がランダムな予測よりも高く、かつモデル間で予測特性に差があることを定量的に示した。 |
| 議論はある？ | 現在のモデルは人間の予測精度には遠く及ばないことや、単一の事象評価ではスコアが大きく変動するため複数事象の平均的な評価が不可欠であること。また、反実仮想的な匿名化手法のさらなる改善や、より広範なイベントプールが必要とされている。 |
