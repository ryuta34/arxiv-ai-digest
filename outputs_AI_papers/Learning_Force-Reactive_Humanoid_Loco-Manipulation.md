# Learning Force-Reactive Humanoid Loco-Manipulation

| 項目 | 内容 |
|---|---|
| どんなもの？ | ヒューマノイドロボットがロボットなしの環境（実演のみ）から学習し、全身の locomotion（移動）とマニピュレーションを統合的に行うためのフレームワーク「FLoRe」を提案している。接触力を考慮した学習を行い、全身のバランスを維持しながら器用な作業を実現する。 |
| 先行研究と比べてどこがすごい？ | 従来の学習手法は主に位置や軌道の追従に限定されていたが、FLoReは接触力を明示的に観測・予測・制御可能な点に優位性がある。これにより、力制御が必要な環境でも高い成功率を達成した。 |
| 技術や手法のキモはどこ？ | ロボットなしで取得できる接触力付きの実演データを使用する点、および「ハイブリッド・コンプライアンス全身コントローラ」により、位置目標を力指令に基づいて動的にシフトさせ、力制御とコンプライアンス（柔軟性）を同時に実現した点。 |
| どうやって有効だと検証した？ | Unitree G1を用い、「台車の押し引き」「箱の回転」「ボード拭き」の3つの接触作業で検証した。その結果、位置のみを学習するポリシーと比較して、成功率が26.7%から80%に劇的に向上した。 |
| 議論はある？ | 力の予測には高い精度が求められるが、学習データにないような極端な環境変化への対応が課題となる。また、実験では成功するが、さらなる複雑な相互作用への適用や、より長期間の安定性の検証が必要である。 |
