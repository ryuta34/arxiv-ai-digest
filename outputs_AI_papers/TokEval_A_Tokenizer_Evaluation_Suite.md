# TokEval: A Tokenizer Evaluation Suite

| 項目 | 内容 |
|---|---|
| どんなもの？ | 大規模言語モデル（LLM）のトークナイザーを評価するための包括的なフレームワーク「TokEval」を提案した論文。従来の圧縮率や語彙数といった指標だけでなく、言語やタスクの特性を考慮した構造的な指標群を導入し、トークナイザーの設計選択がモデル性能に与える影響を系統的に分析した。 |
| 先行研究と比べてどこがすごい？ | 従来手法は圧縮率などの単純な指標に依存しており、下游タスクの性能との相関が不明確であった。本研究は、数学的推論やコード生成など、特定の能力に直結するドメイン特有の構造的指標を新たに提案し、制御された事前学習実験を通じてそれらの予測能力を検証した点。 |
| 技術や手法のキモはどこ？ | UTF-8境界整合性、数式の桁位置合わせ、コードのAST境界整合性など、モデルの演算特性を考慮した多角的な評価指標群の実装。また、モデルの事前学習における「トークナイザー以外の変数を完全に固定」した制御された実験環境を構築し、回帰分析で個別指標の影響を分離した点。 |
| どうやって有効だと検証した？ | 46種類のトークナイザー構成で1.27Bパラメータのモデルを事前学習し、FLORES+（言語理解）、GSM8K、HumanEval、MBPP（数学・コード）などのベンチマークで性能を測定。情報理論的指標が言語モデル能力を、構造的指標がタスク精度を予測することを示した。 |
| 議論はある？ | 実験がnanochatアーキテクチャ（1.27B）に限定されており、より大規模なモデルや他アーキテクチャへの汎化性は未知数。また、AGI的な推論能力や指示追従性能は評価対象外である。指標の有効性はデータ分布に依存するため、すべてのドメインで万能ではない。 |
