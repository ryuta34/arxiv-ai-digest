# Base Models Can Reason By Taking a Cue From Training Data

| 項目 | 内容 |
|---|---|
| どんなもの？ | ベースモデル（事前学習済みモデル）の応答の最初の数トークン（Cue）を固定するだけで、強化学習（RL）と同等の高い推論性能を引き出せることを示した研究。モデルの推論能力は、学習データ内の特定の開始トークンと推論挙動の間の関連付けによって決まることを明らかにしている。 |
| 先行研究と比べてどこがすごい？ | RLなしでもベースモデルの推論能力を最大限に引き出せる点を指摘し、推論能力がRLで「獲得」されるのか、それともRLが既存の能力を「引き出している」だけなのかという問いに対し、後者を支持する強力な証拠を提示した点。 |
| 技術や手法のキモはどこ？ | モデルの応答の最初を「.\n\n Okay」のような特定のトークンCueで強制的に始めることで、学習データ中に存在する推論トレースを呼び出し、モデルの潜在的な推論能力を起動する仕組み。また、学習データの単語を置換することで、任意の単語を推論の引き金に変えられることを実証した。 |
| どうやって有効だと検証した？ | Olmo-3-7BやQwen3-14Bなどのベースモデルを用い、MATH-500などの推論ベンチマークで、Cue導入前後およびRL適用後の性能を比較。さらに、学習データのカウンターファクチュアル（反事実）編集実験や、隠れ状態（hidden state）の類似性解析により、推論能力と学習データの関連を立証した。 |
| 議論はある？ | モデルや事前学習データによってCueの有効性が異なる点（モデル依存性）や、非常に複雑なパイプラインを経たモデルでは本手法だけで完全な代替にならない可能性、学習データがバイアスを含んでいる場合にCueが意図しない挙動（拒絶や有害な反応）を誘発するリスクがある。 |
