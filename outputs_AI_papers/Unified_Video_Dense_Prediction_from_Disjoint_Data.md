# Unified Video Dense Prediction from Disjoint Data

| 項目 | 内容 |
|---|---|
| どんなもの？ | 相互にデータセットの共有がない（Disjoint）データから、深度、法線、セマンティクスなど8つのタスクを同時に予測する統一ビデオモデル「UniD」。拡散モデルの事前学習済み視覚プライアを活用し、個別の専門モデルと競合する性能を実現する。 |
| 先行研究と比べてどこがすごい？ | 従来のマルチタスク学習で必要だった完全なアノテーションの共起や、コストのかかる擬似ラベリングを不要にした点。さらに、動画データのアノテーションが不足していても、静止画と動画の混合データを用いて、高い時間的一貫性とゼロショットの汎化性能を獲得している。 |
| 技術や手法のキモはどこ？ | 各タスクの専門モデル（Expert）から、軽量なタスク専用の「潜伏空間プロジェクター（Latent Projectors）」を通じて知識を蒸留する「潜伏空間の蒸留（Latent Distillation）」を採用した点。これにより、複雑なデコーダーを通す勾配計算なしで学習を統合している。 |
| どうやって有効だと検証した？ | 8つの dense prediction タスクにおいて、NYUv2、KITTI、ScanNet 等の標準ベンチマークで性能を評価。特に未知のドメインに対する汎化性能（OOD Generalization）や、動画における時間的一貫性、タスク間の相関の一貫性について、既存手法や専門モデルと比較検証した。 |
| 議論はある？ | セマンティックセグメンテーションのような分類タスクでは、単純なL1損失による蒸留が一部の情報を欠落させる可能性があるため、追加の微調整が必要であるという限界がある。今後は分類性能をより維持できる学習目的関数の模索が課題。 |
