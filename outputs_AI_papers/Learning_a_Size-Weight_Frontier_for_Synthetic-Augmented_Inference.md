# Learning a Size-Weight Frontier for Synthetic-Augmented Inference

| 項目 | 内容 |
|---|---|
| どんなもの？ | 希少な実データに合成データを追加する際、統計的な推論の妥当性（信頼区間の被覆確率）を維持しながら、どの程度の量と重みで合成データを混ぜるべきかを自動調整する枠組み。|
| 先行研究と比べてどこがすごい？ | 従来の手法は合成データのサイズ調整のみに焦点が当てられていたが、本手法は合成データの個数と重みを同時に調整可能な「サイズ・重みフロンティア」を導入した点。また、過去の類似タスクからこのフロンティアを学習し、未知の新しいタスクに対しても統計的妥当性を保証できる。 |
| 技術や手法のキモはどこ？ | 統計的な「サイズ・重みフロンティア」を定義し、過去の複数タスク（キャリブレーションデータ）から、信頼区間の被覆確率を維持する境界線をデータ駆動的に推定するアルゴリズム。|
| どうやって有効だと検証した？ | 大規模な世論調査データ（WorldValuesBench）を用い、GPT-4oやGPT-5 miniで生成した合成データで検証。推定されたフロンティアが理論的な被覆率を維持しつつ、合成データの追加により信頼区間の幅を効率的に狭められることを確認した。 |
| 議論はある？ | 現在の理論保証はタスク分布に対する周辺的なものに留まる。今後は、個別のタスクの特徴量に応じて、分布の変化に耐性のある「タスク条件付き」のフロンティア開発が必要。 |
