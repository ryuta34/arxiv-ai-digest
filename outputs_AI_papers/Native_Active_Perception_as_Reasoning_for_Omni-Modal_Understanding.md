# Native Active Perception as Reasoning for Omni-Modal Understanding

| 項目 | 内容 |
|---|---|
| どんなもの？ | 長尺動画の理解を「受動的な全フレーム処理」から「POMDP（部分観測マルコフ決定過程）に基づく能動的な推論プロセス」へと再定義した初のオムニモーダル・エージェント「OmniAgent」。クエリに基づいて必要な音声・映像情報を選択的に抽出することで、動画の長さに依存せず、推論の複雑さに応じた計算リソース配分を可能にしました。 |
| 先行研究と比べてどこがすごい？ | 従来のモデルが全フレーム処理で計算コストが動画長に対して増加するのに対し、本手法は推論のステップ数のみに依存するため、1時間を超える長尺動画でも効率的に推論可能です。また、7Bという軽量なモデルサイズでありながら、10倍のパラメータを持つQwen2.5-VL-72Bを超える性能をLVBench等のベンチマークで達成しています。 |
| 技術や手法のキモはどこ？ | (1) 観察・思考・行動(OTA)サイクルによる反復的な情報蒸留、(2) トークンレベルのエントロピーを用いて、意思決定の分岐点（fork）を特定・強化する学習手法「TAURA」、(3) 冗長な未処理データを適宜破棄し、重要な情報のみをテキストメモリに保持するメモリ管理機構。 |
| どうやって有効だと検証した？ | VideoMME, LVBench, MLVU, LongVALEなど10種類のベンチマークで評価し、既存のオープンソースモデルを凌駕するSoTA性能を確認。また、推論ターンの増加に伴う精度向上（正のテスト時スケーリング）や、パラメータ効率の高さ、動画の長さに依存しない安定した計算コストを定量的に証明しました。 |
| 議論はある？ | 現在のシーケンシャルなアクション実行は推論時間の遅延（レイテンシ）を招く点。今後は、この制約を解消するために探索を並列化する手法の検討が必要であるとしています。 |
