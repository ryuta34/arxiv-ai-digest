# MOCHI: Motion Enhancement of Collaborative Human-object Interactions

| 項目 | 内容 |
|---|---|
| どんなもの？ | 複数の人間が協力して物体を操作する状況（MHOI）における、ノイズを含んだモーションキャプチャデータの品質を向上させる手法。人体と物体の相互作用を考慮し、不自然な動きや接触の不整合を修正して、物理的に妥当かつ自然な全身・手のモーションを生成する。 |
| 先行研究と比べてどこがすごい？ | 従来手法が単一人物の相互作用に限定されていたのに対し、複数人による複雑な協力動作（持ち上げ、手渡し等）を扱える点。また、データ収集が困難なMHOIにおいて、ノイズの多い既存データや生成モデルの出力を高品質化し、データ拡張ツールとしても活用できる点。 |
| 技術や手法のキモはどこ？ | 手と物体の接触を推定し、拘束付き最適化によって物理的に整合性の取れた「手」の動作を生成する段階と、単一人物の拡散モデル（Diffusion Model）をベースに、複数人のインタラクション制約（相互作用グラフ、衝突回避など）を組み込んで「全身」の動きを精緻化する2段階のフレームワーク。 |
| どうやって有効だと検証した？ | CORE4D等の既存データセットや生成モデル（OMOMO）の出力を対象に、接触の精度（F1スコア）、物理的な妥当性（貫通の有無）、自然さ（足の滑り、ジッター）を定量的に比較。さらに、キーフレームからの生成や多様な物体への適用実験を行い、定性的にも妥当性を確認。 |
| 議論はある？ | 入力データのノイズが過剰で相互作用の意味が解読できない場合や、極端な速度変化を含む動作には対応できない。また、接触状態が刻々と変化する非常に複雑な動作（空中で投げて別の手でキャッチするなど）の処理にはまだ限界がある。 |
