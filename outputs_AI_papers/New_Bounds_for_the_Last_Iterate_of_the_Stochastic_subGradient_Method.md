# New Bounds for the Last Iterate of the Stochastic subGradient Method

| 項目 | 内容 |
|---|---|
| どんなもの？ | 確率的劣勾配法（SsGM）における最終反復点の収束性を解析した論文。標準的なステップサイズ $\eta = \Theta(1/\sqrt{n})$ において、ノイズに特定の対称性（時間斉次性および状態独立性）が備わっている場合には $1/\sqrt{n}$ の最適レートが得られる一方、それらが欠けると $\log(n)/\sqrt{n}$ という劣最適なレートになることを理論的に証明した。 |
| 先行研究と比べてどこがすごい？ | 従来、固定次元での最終反復点の最適性については議論が分かれていたが、本研究はノイズの性質と収束レートの関係を明示的に解明し、Open Problem 1 of [9] に否定的な回答（反例による証明）を与えた点。また、特定の条件下では$1/\sqrt{n}$を達成できることを示した点も大きな貢献である。 |
| 技術や手法のキモはどこ？ | マルコフ連鎖の理論とFoster-Lyapunov型ドリフト不等式を用いて、劣勾配法を一般的な状態空間上のマルコフ過程として再定式化した点。特に、目的関数の劣最適性が時間とともにどう変化するかを評価するために、1次元の確率過程を支配する「片側ランダムウォーク」を構築した手法が核心的。 |
| どうやって有効だと検証した？ | 理論的な上界（定理2）と下界（定理3）の双方を証明することで有効性を検証。下界の証明では、状態依存的または時間非斉次的なノイズ生成メカニズム（「ラベル付き状態」への稀な大きなノイズ）を巧妙に構成し、特定のステップサイズポリシーで対数因子が不可避であることを示した。 |
| 議論はある？ | 現在の結果は1次元の設定に焦点を当てている。著者らは、決定論的な多変量設定（固定次元 $d>1$）において最終反復点が最適かどうかを解明することを将来の課題として挙げている。 |
| 次に読むべき論文は？ | [9] Koren and Segal (2020), [18] Shamir and Zhang (2013), [20] Zamani and Glineur (2025) |
