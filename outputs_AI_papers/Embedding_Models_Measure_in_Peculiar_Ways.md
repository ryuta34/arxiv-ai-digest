# Embedding Models Measure in Peculiar Ways

| 項目 | 内容 |
|---|---|
| どんなもの？ | 現代のテキスト埋め込みモデルが、質量・距離・時間などの物理量表現をどの程度正確に捉えているかを調査した研究。これらのモデルの類似度計算が物理的な意味よりも、表面的な文字列の類似性に強く依存していることを明らかにした。 |
| 先行研究と比べてどこがすごい？ | 既存の大規模ベンチマーク（MTEB等）では見過ごされがちな「物理的測定値」の理解度に着目し、24種類の主要な埋め込みモデルを網羅的に検証した点。モデルの規模やアーキテクチャにかかわらず、物理的な距離関係の理解が著しく欠如していることを実証した。 |
| 技術や手法のキモはどこ？ | 物理単位や測定値を用いて「物理空間」と「埋め込み空間」の整合性を検証するベンチマーク「PhysScore」を構築した点。また、文字列レベルおよびトークンレベルの類似度と、モデルの埋め込み類似度の相関を分析し、数値のセマンティクスではなく表面的な文字列形式が判断基準になっていることを突き止めた。 |
| どうやって有効だと検証した？ | 24個の埋め込みモデルに対し、多様な単位（メーター、キログラム等）とスケール（Local, Medium, Log等）を用いた類似度計算を行い、ヒートマップによる視覚的分析と、順序付けの正確さを測る「PhysScore」を用いた量的評価を実施した。 |
| 議論はある？ | 物理的測定値の整合性が低く、モデルのスケールアップでも解決しない。対照学習の目的関数自体が物理・量的関係の学習に不十分である可能性を指摘している。今後は数値処理や物理的な推論が必要なエージェントシステム等において課題となる。 |
