# In-Context Robot Learning with VLM Agents

| 項目 | 内容 |
|---|---|
| どんなもの？ | 汎用的な視覚言語モデル（VLM）を、追加学習やパラメータ更新なしでロボット制御に応用する「GPT-Policy」フレームワーク。人間やロボットのビデオ、目標画像、インタラクション履歴などの「文脈（コンテキスト）」を入力として、ロボットの動作を生成・適応させる手法。 |
| 先行研究と比べてどこがすごい？ | 従来の専用モデルとは異なり、事前のポリシー学習なしで、デプロイ時に提供されたコンテキストのみを用いて未知のタスクに即座に適応できる点。VLMの広範な推論能力とロボットの物理的な閉ループ制御を橋渡しするコンテキストコンパイラを導入した。 |
| 技術や手法のキモはどこ？ | コンテキスト（指示、ビデオ、目標画像など）を「コンテキストコンパイラ」で構造化してVLMに入力し、VLMが提案したパラメータ化された動作を「拘束付き実行層（constrained execution layer）」が検証して実行・フィードバックする閉ループ制御インターフェース。 |
| どうやって有効だと検証した？ | 5つのコンテキスト（模倣、接触、目標追従、探索、対人協力）に関連する実機ロボット実験を実施。成功率、意思決定数、実行時間を指標とし、コンテキストの有無による比較および各コンテキストの有用性を検証した。 |
| 議論はある？ | VLMによるタスク理解や適応は可能だが、正確な接触制御、物理的な安全性、成功の信頼性には依然として課題が残る。特に腕同士の衝突や、物理的ダイナミクスへの適応については、専用の安全層や低レベル制御との統合が必要。 |
