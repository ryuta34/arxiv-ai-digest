# HARMONY: Hierarchical Agentic Reasoning for MONocular Image-to-Scene Synthesis

| 項目 | 内容 |
|---|---|
| どんなもの？ | 単一の室内画像から、階層的な推論を行うVLM（視覚言語モデル）と幾何学的な基礎モデルを組み合わせることで、高精度な3D室内シーンを再構成するフレームワーク「HARMONY」。 |
| 先行研究と比べてどこがすごい？ | 従来のVLMベース手法が抱えていた「幾何学的精度の低さ」と、幾何学モデルベース手法が抱えていた「セマンティック（意味的）な一貫性の欠如」を克服し、オブジェクト間の関係性（「上に載っている」「壁に接している」等）を保ったまま、入力画像と幾何学的に整合性のとれたシーン生成を実現した点。 |
| 技術や手法のキモはどこ？ | 壁面要素→家具→装飾品という階層的な順序でオブジェクトを配置する「階層的Chain-of-Thought」と、各配置段階でレンダリング結果と入力を比較・修正する「リフレクティブ（反射的）なフィードバックループ」により、段階的なエラーの蓄積を抑制している点。 |
| どうやって有効だと検証した？ | 合成データセット（Front3D）と、実写を含む独自ベンチマーク（HARMONY300）を用いて、N-CLIPやPSNR、幾何学的なChamfer Distanceなどで評価。さらに人間による主観評価（ユーザースタディ）を行い、他手法よりも高いランキング結果を獲得した。 |
| 議論はある？ | まれなオブジェクト種別の誤認識や、カメラに近い場所での重度なオクルージョンによるメッシュの歪みが課題。また、現在のパイプラインは順次処理のため推論時間に依存するという制限がある。 |
