# LongZero: Enhancing Long-Context Reasoning in LLMs from Zero Data

| 項目 | 内容 |
|---|---|
| どんなもの？ | 長文脈推論の強化を目的とした、外部データや人手のアノテーションに頼らない強化学習手法「LONGZERO」を提案。モデルが自ら長文脈の課題を作成・解答し、その過程で学習を行うことで、長文脈推論能力を向上させる手法。 |
| 先行研究と比べてどこがすごい？ | 外部コーパスや強力な教師モデルに依存せず、モデル自身が推論課題（推論タスクおよび検索タスク）を合成できる点。また、合成した課題のうち、モデルが適切に回答できる（かつ学習のシグナルが得られる）ものをフィルタリングして学習に用いる点が優れている。 |
| 技術や手法のキモはどこ？ | モデルがまず「世界指定書（質問・エビデンス・回答）」を短い構造化形式で生成し、その後に長文へ展開する「トップダウン型」の生成順序を採用した点。また、モデル自身の回答の正誤に基づき、学習に効果的な難易度の課題のみを抽出する「不安定バンド（unstable band）」フィルタリングが核心。 |
| どうやって有効だと検証した？ | 2つのベースモデル（Qwen3）に対し、5つの長文脈推論ベンチマーク（LongBench, LongBench v2, FRAMES, AA-LCR, LongReason）を用いて評価。外部データを用いた合成手法よりも高い平均スコアを達成し、かつ未知の実タスクへの汎化能力を確認。 |
| 議論はある？ | 短い合成データで学習しても、はるかに長い実タスクへ汎化できる一方で、依然として合成データ特有の限界がある。今後は、より長文の文脈の生成、計数や比較など多様な質問タイプの追加、およびデータ精度の更なる保証が将来課題となる。 |
