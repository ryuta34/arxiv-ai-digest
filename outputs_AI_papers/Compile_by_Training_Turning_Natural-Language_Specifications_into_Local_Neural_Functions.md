# Compile by Training: Turning Natural-Language Specifications into Local Neural Functions

| 項目 | 内容 |
|---|---|
| どんなもの？ | 自然言語で記述された仕様から、再利用可能な軽量なニューラル関数を自動生成する「Compile by training」という手法。大規模言語モデルをランタイムではなく「ツール構築者」として活用し、小規模で高速な専用プログラムを生成する。 |
| 先行研究と比べてどこがすごい？ | 従来の「Program-as-Weights (PAW)」が単一の推論でプログラムを予測するのに対し、本手法は教師モデルによる合成データを用いた追加学習（ファインチューニング）を行うことで、計算時間をわずかに増やす代わりに高いセマンティック精度（83.6%）を実現した点。 |
| 技術や手法のキモはどこ？ | 大規模モデルに仕様に基づいた大量のタスク例を生成させ、それを教師データとして軽量なLoRAアダプターを最適化する点。コンパイルプロセスと実行環境を分離し、生成された成果物をポータブルなアーティファクトとして保存・再利用可能にした点。 |
| どうやって有効だと検証した？ | 「FuzzyBench-Hard」ベンチマークを用い、PAWの高速コンパイラでは正解できなかった課題に対して本手法が大幅な精度向上（0.224から0.836へ）を達成したことを実証。また、マルチサイト・ヘルパーや3Dアバター制御などの実用アプリケーションで動作を検証した。 |
| 議論はある？ | 合成データが教師モデルの誤りを継承するリスクがある。厳密な正当性が求められるアプリケーションには、出力検証や決定論的な制御パスの保持が必要であると述べている。 |
