# TokenLight: Precise Lighting Control in Images using Attribute Tokens

| 項目 | 内容 |
|---|---|
| どんなもの？ | 画像内の照明（強度、色、拡散度、3D位置など）を、属性トークンを用いて高精度かつ直感的に編集できる拡散モデルベースの画像リライティングフレームワーク。明示的な3D再構成を行わずに、照明の変化に対して幾何学的に整合性のとれた自然な結果を生成する。 |
| 先行研究と比べてどこがすごい？ | 従来の明示的な3D再構成や複雑な環境マップ操作に依存せず、画像ドメイン上で直接的かつ空間的にローカライズされた照明編集が可能。また、カメラ視点に依存しない「シーン非依存」な照明パラメータ設定により、一貫したライティング制御を実現した点。 |
| 技術や手法のキモはどこ？ | 照明属性を「物理的に意味のあるトークン（Attribute Tokens）」として表現し、拡散トランスフォーマーの入力シーケンスに組み込んだ点。さらに、合成データを用いた大規模な事前学習と、実写データによる微調整を組み合わせることで、複雑な幾何学的交互作用を学習している。 |
| どうやって有効だと検証した？ | 合成データセット（Objaverse）を用いたPSNR、SSIM、LPIPS等の定量的評価に加え、実写画像を用いた「VisibleFixture-60」ベンチマークでの比較評価、および他手法（GenLit, Careaga et al.）との定性的な比較・ユーザー評価を実施。 |
| 議論はある？ | 現在のモデルは大規模なDiTアーキテクチャに依存するためリアルタイム性が課題であること、拡散モデル特有のサンプリング時の確率的なばらつき（乱数シード依存）、および屋外環境への汎化性能向上が今後の課題である。 |
