# VibeVideoBench:Evaluating Multimodal Agents on Code-Driven Video Generation

| 項目 | 内容 |
|---|---|
| どんなもの？ | コードベースのマルチモーダル生成AIエージェントを評価するための大規模ベンチマーク「VibeVideoBench」の提案。12カテゴリ・239タスクのタスクセットを用い、エージェントがコードを書いてMP4形式の動画（音声・ナレーション含む）を生成する能力を検証している。 |
| 先行研究と比べてどこがすごい？ | 既存の動画生成評価（短いサイレント動画を生成する手法）やコード生成評価（静的成果物）と異なり、エージェントが自律的にツールを使い、プログラムを書いて動画を完結させるプロセス全体を評価する。さらに、プログラムチェックとマルチモーダルLLM judgeを組み合わせた階層的な評価プロトコルにより、再現性と信頼性を高めている。 |
| 技術や手法のキモはどこ？ | プログラムによる検証（L1）、task-specificな1.3万件のルーブリックに基づくVLM judge（L2）、5つの品質評価軸（L3）という三層構造の評価手法。また、音声と視覚の判定を適切に行うために、モダリティに応じて評価モデルを振り分けるルーティングを採用している点。 |
| どうやって有効だと検証した？ | 9つの主要なAIエージェントシステム（GPT-6 Astra, Claude Opus 5.5等）で2,151回のロールアウトを実施。人間のブラインド選好投票によるEloレーティングと、LLM judgeによる評価の一致を確認し、システム順位付けの有効性を検証した。 |
| 議論はある？ | 動画が生成されない失敗要因の多くが「時間管理（終了直前の処理）」にあること。また、評価モデル（LLM judge）はシステムランク付けには優れているが、個々の動画に対する判定精度には限界があり、人間の好みと完全に一致するわけではない点が課題。 |
| 次に読むべき論文は？ | [VBench [21]](https://arxiv.org/abs/2311.17982)や[AgenticVBench [6]](https://arxiv.org/abs/2605.27705)、[VideoScore [18]](https://arxiv.org/abs/2404.09341)など、動画生成・動画評価に関連する先行研究。 |
