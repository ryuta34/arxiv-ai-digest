# ACE-Data-0: Human-Centric Ambient Capture as Embodied Data Engine

| 項目 | 内容 |
|---|---|
| どんなもの？ | リアルな家庭環境を記録スタジオ化し、身体・手・物体の動作、音声、触覚など複数のモダリティを完全に同期・整合して記録する「Ambient Capture Engine (ACE)」と、それを用いた大規模データセット「ACE-Data-0」を提案した研究。 |
| 先行研究と比べてどこがすごい？ | 既存のデータセットでは断片化されていた視点（一人称・三人称）、空間スケール（手元・部屋全体）、物理的な整合性（同期・世界座標系）を、本研究ではすべて統合し、長期間の日常活動を一貫してキャプチャした点。 |
| 技術や手法のキモはどこ？ | オプティカルモーションキャプチャを基準とした共通の時空間フレームでの厳密な同期、および「テーブルスケール」と「ルームスケール」という2つの補完的な環境構成による、マルチモーダルかつスケーラブルなデータ収集パイプライン。 |
| どうやって有効だと検証した？ | 150時間の日常活動データ（1700万フレーム、7.5万エピソード）を収集し、触覚推論、人間と物体のモーション推定、および一人称・三人称視点を用いたヒューマン・オブジェクト・インタラクション（HOI）のタスクで30以上の既存手法を評価した。 |
| 議論はある？ | 対象環境が2箇所に限定されている点、スキャンやマーカーが必要な制約がある点、スーツや手袋などのセンサが視覚的に映り込む点が挙げられ、今後のさらなる多様性や非拘束なセンシングが課題である。 |
