# SoftCache: Adaptive Step Size Caching for Diffusion Transformers

| 項目 | 内容 |
|---|---|
| どんなもの？ | 拡散モデルおよびフローモデルの推論を加速するための、トレーニング不要な動的キャッシング手法「SoftCache」。従来の「ハードキャッシング（更新か再利用かの二択）」に対し、キャッシュの信頼度（ヘッドルーム）に基づいてステップサイズを動的に適応させる手法です。 |
| 先行研究と比べてどこがすごい？ | 従来の動的キャッシュは固定されたスケジューリンググリッドに縛られていましたが、SoftCacheは信頼度に応じてステップサイズを連続的に変えることで、グリッド外への「ジャンプ」を可能にしました。FLUXやHunyuanVideo等の最新モデルにおいて、追加の学習なしで従来手法を上回る速度と忠実度（FID指標等）を達成しています。 |
| 技術や手法のキモはどこ？ | キャッシュがどれだけ信頼できるかを示す「ヘッドルーム（しきい値までの距離）」をステップサイズに変換し、長いステップで複数のノードをスキップさせる点。また、飛ばしたノードの埋め合わせとして残りの軌道を再配置し、キャッシュした残差を線形補間（残差運動）することで、計算コストを増やさずに高精度を維持する点です。 |
| どうやって有効だと検証した？ | FLUX（画像）、HunyuanVideoおよびWan2.1（動画）の各バックボーンを用い、PSNR、SSIM、LPIPS、DreamSimなどの忠実度メトリクスを使用して比較。既存のTeaCache、SeaCache、DPCache等に対し、同等の速度帯域ですべてのメトリクスを上回る結果を示しました。 |
| 議論はある？ | PSNR（平均二乗誤差ベース）が細部の保持よりも滑らかさを優先する傾向があるため、より詳細な質感の評価にはLPIPSやDreamSimといった知覚的メトリクスが重要であると論じています。また、極端な速度向上時には高周波成分の損失が見られることがあり、その際のパラメータ（$\beta$など）の調整が重要です。 |
| 次に読むべき論文は？ | [SeaCache](https://arxiv.org/abs/2606.06060)（ベースとなる動的キャッシュ手法）、[DPCache](https://arxiv.org/abs/2606.04362)（比較対象のパス計画ベースの手法）、[TeaCache](https://arxiv.org/abs/2508.07356)（比較対象の動的キャッシング手法） |
