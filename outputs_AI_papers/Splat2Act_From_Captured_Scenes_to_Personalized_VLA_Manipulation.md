# Splat2Act: From Captured Scenes to Personalized VLA Manipulation

| 項目 | 内容 |
|---|---|
| どんなもの？ | ユーザーの家庭やオフィスをスマートフォンでスキャンするだけで、ロボットの操作学習用デジタルツインを自動構築する「Splat2Act」というリアル・ツー・シム・ツー・リアル（Real-to-sim-to-real）のパイプライン。特別なロボット操作（テレオペレーション）や注釈作業を一切必要とせず、一般的な汎用操作モデル（VLA）を特定のユーザー環境向けに最適化する手法。 |
| 先行研究と比べてどこがすごい？ | 手作業による注釈やテレオペレーションが不要で、建物スケールの環境を丸ごとデジタルツイン化できる点。また、幾何学的な情報から自動で受け皿（テーブル等）を検出し、シミュレーション内で大規模な試行錯誤を自動生成することで、現実環境への高い適応性を実現している点。 |
| 技術や手法のキモはどこ？ | 3D Gaussian Splatting (3DGS)を用いたフォトリアルなシーン再構成と、SuGaRによる表面メッシュ抽出による物理シミュレーション対応。これに加えて、幾何学的な受け皿発見機能、および特権的なシミュレーションオラクルを用いた、テレオペ不要の自動デモンストレーション生成パイプライン。 |
| どうやって有効だと検証した？ | 101箇所の建物スケールの環境で68,021件の試行データを生成し、実機（Stretch 3）を用いて検証。同じシーンでの「広範な適応学習（Stage 1）」と「個人化学習（Stage 2）」を組み合わせることで、オフセットのないベースモデルで0%だった成功率を、実環境で63.9%まで向上させた。 |
| 議論はある？ | シーン特有の個人化は非常に強力だが、未知の環境（OOD）へ転移した際は性能が低下することから、汎用性と個人化のバランスが課題。また、大規模シミュレーションデータセットを生成するための計算コストや、複雑な環境下でのシミュレーションと実環境の物理ギャップ（接触精度の差など）が議論されている。 |
