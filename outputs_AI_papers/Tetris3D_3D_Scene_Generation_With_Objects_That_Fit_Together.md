# Tetris3D: 3D Scene Generation With Objects That Fit Together

| 項目 | 内容 |
|---|---|
| どんなもの？ | 単一画像から、物理的および幾何学的に整合性のとれた3Dシーンを再構築する生成フレームワーク「Tetris3D」。隣接オブジェクトの形状や物理的関係を明示的に考慮して、オクルージョン（隠蔽）がある場合でも高精度なシーン再構築を実現する。 |
| 先行研究と比べてどこがすごい？ | 既存の独立したオブジェクト生成手法とは異なり、空間的文脈と物理的関係を条件として生成に組み込む点。また、大規模なシミュレーションベースのデータセット「ComOb」を構築し、物理的に安定した配置を学習・再現できる点が優れている。 |
| 技術や手法のキモはどこ？ | オブジェクト間の依存関係をVLM（視覚言語モデル）で推論し、物理的に正しい順序で自己回帰的に生成する点。また、可視領域から不可視領域を推論する「Visible-to-Invisible (V2I) Attention」や、隣接物の表面距離などを空間文脈として注入する機構が核心。 |
| どうやって有効だと検証した？ | Toys4K, MessyKitchens, Picassoなどのデータセットを用い、再構築品質（Chamfer Distance等）、生成品質（FID等）、物理的安定性（貫通深度やシミュレーション後の変位）を定量・定性的に評価。既存のシーン生成およびアモーダル生成手法を上回る性能を示した。 |
| 議論はある？ | 現在の手法は学習済みのモデルに依存しており、深度推定やセグメンテーションの誤りが生成過程で伝播する可能性がある点。また、物理的な整合性は学習ベースのガイダンスであり、ハードな制約ではないため、必ずしもすべてのケースで完全に物理的に正しいとは限らない。 |
