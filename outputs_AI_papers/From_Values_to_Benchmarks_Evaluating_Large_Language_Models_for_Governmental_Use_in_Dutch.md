# From Values to Benchmarks: Evaluating Large Language Models for Governmental Use in Dutch

| 項目 | 内容 |
|---|---|
| どんなもの？ | オランダの行政機関（アムステルダム市）での利用を想定し、LLMを評価・選定するための実用的なフレームワーク「Grip on LLMs」を提案している。30以上のモデルを対象に、行政特有のニーズや価値観に基づいた多角的な評価を実施し、非専門家でも直感的に理解できるリーダーボードを公開している。 |
| 先行研究と比べてどこがすごい？ | 既存のリーダーボードが技術的指標に偏り、行政の実務担当者にとって不親切であった点を改善している。法規制への対応やエネルギー効率、倫理的側面を評価項目に取り入れ、Dutch（オランダ語）環境での政府ニーズを包括的にカバーした点が新しい。 |
| 技術や手法のキモはどこ？ | 行政のエキスパートやユーザーへのインタビューとアンケートから、「事実性」「誠実性」「社会バイアス」「環境負荷」「コスト」「学習データの透明性」という6つの重要評価次元を特定・構築した点。また、Rawスコアではなく、非専門家が判断可能なカテゴリ別評価（1〜5段階）に変換して提示している。 |
| どうやって有効だと検証した？ | 30以上の多言語およびオランダ語特化型モデルを対象に、収集した6次元の指標に基づいてベンチマークを実施。特にモデルの「事実性」と「誠実性」が異なる特性であることを示し、単一指標での評価の危険性を実証データを用いて示した。 |
| 議論はある？ | 単一スコアへの圧縮による情報の単純化（過度の簡略化）や、ベンチマークが必ずしも現実の行政業務の品質を保証するわけではないという限界がある。また、安全性の評価が不足していることや、オランダ語のRAGベンチマークの欠如を将来課題として挙げている。 |
