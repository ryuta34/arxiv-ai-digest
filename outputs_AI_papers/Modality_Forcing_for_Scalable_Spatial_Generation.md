# Modality Forcing for Scalable Spatial Generation

| 項目 | 内容 |
|---|---|
| どんなもの？ | 既存の学習済み画像生成モデル（T2Iモデル）を事後学習させることで、画像と深度マップの双方を生成・変換できるモデルを作成する手法「Modality Forcing」を提案。単一の拡散Transformer（DiT）で、深度推定、深度から画像への変換、画像と深度の同時生成という3つの空間的タスクを統一的に実現する。 |
| 先行研究と比べてどこがすごい？ | 密な教師データが不要で、疎な実世界の深度データから学習可能。また、モデルの規模が大きくなるほど性能が向上するスケーラビリティを確認し、既存のマルチモーダル生成モデル（JointDiTなど）と比較してAbsRelを57%改善するなど、最高水準の性能を達成した。 |
| 技術や手法のキモはどこ？ | RGBと深度それぞれに独立したノイズレベルを割り当て、学習時にModality Forcingアルゴリズムを用いる点。さらに、深度をピクセル空間で直接トークン化し、推論時にモダリティごとのノイズスケジュールを調整することで、条件付けの強弱を柔軟に変更できる点にある。 |
| どうやって有効だと検証した？ | 370Mから3.3BパラメータまでのDiTを用いた制御されたスケーリング実験を行い、モデル規模とデータ量の増加が深度予測精度に寄与することを証明。NYUv2、KITTI、ETH3Dなどの主要なベンチマークで、最新の専門モデルや先行の画像・深度生成モデルと比較評価した。 |
| 議論はある？ | 現在の実験は最大3Bパラメータまでに制限されており、フルスケーリング則は導出できていない。また、深度データがT2I学習データと比較して圧倒的に少なく、データ量を増やすことでさらなる性能向上が見込まれること、メトリック（実測）深度予測への課題が挙げられている。 |
