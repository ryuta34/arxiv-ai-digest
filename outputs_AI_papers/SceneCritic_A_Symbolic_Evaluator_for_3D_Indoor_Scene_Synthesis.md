# SceneCritic: A Symbolic Evaluator for 3D Indoor Scene Synthesis

| 項目 | 内容 |
|---|---|
| どんなもの？ | 3D屋内シーンのレイアウト生成を、レンダリング画像に頼らず、構造化された空間オントロジーに基づいてシンボリックに評価するフレームワーク「SceneCritic」です。従来のVLM（Vision-Language Model）による評価が抱えていた、視点やプロンプトに対する不安定性や幻覚といった課題を解決します。 |
| 先行研究と比べてどこがすごい？ | 従来のVLMベースの評価指標が視覚的なレンダリング結果に過度に依存するのに対し、レイアウトの中間構造を直接評価することで、視点によらない安定した評価を可能にしました。また、人間による評価との相関が極めて高く、特に複雑なシーンにおいて圧倒的な精度を誇ります。 |
| 技術や手法のキモはどこ？ | 3D-FRONT、ScanNet、Visual Genome等の大規模データセットから統計的優先順位（オブジェクトの共起確率、スケール、向きの統計）を抽出した空間オントロジー「SceneOnto」を構築し、それに基づく制約充足によってレイアウトの妥当性を厳密に検証する点です。 |
| どうやって有効だと検証した？ | 16人の注釈者による594件の人間による評価データと比較し、SceneCriticが人間と極めて高い合意率を示すことを証明しました。また、生成モデルの推論過程を反復的に評価するテストベッドを構築し、テキストのみのLLMが既存のVLMよりも高い性能を発揮する場合がある等の知見を得ました。 |
| 議論はある？ | 現在の評価は、オントロジーに含まれるオブジェクトカテゴリ（79種類）に限定されています。今後は新しいデータセットの追加によるカテゴリの拡張や、より高度な機能的関係性を持つ複雑な空間への対応が課題です。 |
