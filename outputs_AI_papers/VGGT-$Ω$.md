# VGGT-$Ω$

| 項目 | 内容 |
|---|---|
| どんなもの？ | 大規模なデータとモデルスケーリングを可能にした、フィードフォワード型の3D再構成モデル「VGGT-Ω」。静的および動的なシーン双方において、高精度かつ効率的な再構成を実現し、空間理解のための汎用的な特徴抽出器としても機能する。 |
| 先行研究と比べてどこがすごい？ | 従来手法（VGGTなど）と比較して、GPUメモリ消費を約70%削減しつつ、15倍の教師データで学習可能。Sintelベンチマークにおいてカメラ推定精度で77%、深度推定精度で26%の改善を達成し、かつ既存の最適化ベース手法より50倍高速。 |
| 技術や手法のキモはどこ？ | 全フレーム間のグローバルアテンションを制限する「レジスターアテンション（シーントークン）」の導入、および高メモリ消費なCNN層をMLPとピクセルシャッフルに置き換えた設計。また、動的シーンにも対応した大規模なデータ注釈パイプラインを構築した点。 |
| どうやって有効だと検証した？ | 7 Scenes, NRGBD, ETH3Dなどの静的ベンチマークと、DyCheck, Sintel, TUM-Dynamicなどの動的ベンチマークで性能を評価。さらに、ロボット操作（VLA）や言語アライメントタスクへの適用を通じて、特徴表現の汎用性を検証。 |
| 議論はある？ | 激しいモーションブラーや極端な画角の変化に弱い点、学習データに含まれるマスク済みコンテンツ（顔や商標など）の影響で一部の予測が不安定になる点。また、自己教師あり学習の性能向上がまだ難しいという課題がある。 |
