# VLK: Learning Humanoid Loco-Manipulation from Synthetic Interactions in Reconstructed Scenes

| 項目 | 内容 |
|---|---|
| どんなもの？ | 3Dガウススプラッティング（3DGS）を用いて再構成した屋内シーン内で、人手によらず自動生成した大量のデータを用いて学習する、人型ロボットの「Vision-Language-Kinematics（VLK）」ポリシー。視覚情報と自然言語指示から、全身の運動計画（Kinematics）を生成し、実環境でのロコ・マニピュレーション（移動と操作）を実現する。 |
| 先行研究と比べてどこがすごい？ | 既存研究では不足していた「視覚、言語、全身運動」が同期した大規模な教師データセットを、シミュレーションと実世界の橋渡し（Sim-to-Real）を通じて自動生成した点。特に人手による遠隔操作データに依存せず、48,000件もの学習データを自動構築し、実機でのゼロショット展開に成功している。 |
| 技術や手法のキモはどこ？ | 3DGSで再構成した環境に対し、特権的情報を利用した「ロボット動作の合成」と「エゴセントリック視点での後付けレンダリング」の分離にある。また、ポリシーが全身の軌跡を予測し、トラッカーがそれを実行するという分離構造を採用し、データ生成の効率化と実世界への適用能力を両立させている。 |
| どうやって有効だと検証した？ | MuJoCoシミュレーション環境での1,000件ずつのロールアウト評価と、物理的なUnitree G1ロボットを用いた実環境（ラボとアパート）での試験を実施。ナビゲーションおよび箱の持ち運び等のタスクにおいて、合成データによる訓練が実機性能を大幅に向上させることを示し、ドメインランダム化の重要性も併せて証明した。 |
| 議論はある？ | 現在の合成手法はOMOMOデータセットのカバレッジに依存しているため、小型物体の精密な操作には対応できていない。また、現時点では wrist-object コンタクトの安定性に限界があり、将来的にはより複雑な操作スキルや、より汎用的な低レベルコントローラーの統合が課題である。 |
