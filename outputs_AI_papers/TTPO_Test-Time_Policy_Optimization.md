# TTPO: Test-Time Policy Optimization

| 項目 | 内容 |
|---|---|
| どんなもの？ | ラベルなしのテスト時訓練（TTT）において、モデル自身の多数決で得た擬似ラベルを用いて推論能力を向上させる手法「TTPO (Test-Time Policy Optimization)」を提案した。正解ラベルが存在しない環境でも、モデルの推論を強化し、教師あり学習に近い性能を実現する。 |
| 先行研究と比べてどこがすごい？ | 従来の強化学習のみや、誤ったラベルにより学習が崩壊しやすい単純な自己蒸留と異なり、擬似ラベルの誤りを許容する非対称な目的関数を採用した点。これにより、モデルの自己進化を可能にし、ベースモデルの性能を大幅に引き上げる。 |
| 技術や手法のキモはどこ？ | 擬似ラベルと一致する rollout には条件付き教師による「蒸留（OPSD）」を、不一致のものには強化学習「GRPO」を適用する非対称な設計。さらに、トークンごとの重要度に基づいた重み付けや、自信のある誤りだけを標的にするマスク処理により、ノイズの影響を最小化した点。 |
| どうやって有効だと検証した？ | Qwen3-1.7B/4B/8Bを用い、AIMEやHMMT等の5つの競技レベル数学ベンチマークで評価。完全なラベルなし設定で、ラベルありの既存手法と同等以上の性能を達成し、かつ思考モードをオフにしても大幅な性能向上を確認した。 |
| 議論はある？ | サンプル予算が極端に少ない場合や、正解が得られないほど困難な問題では投票信号が劣化する点。また、数学以外の分野（コード生成等）への一般化や、訓練過程でのハイパーパラメータの動的調整が今後の課題である。 |
| 次に読むべき論文は？ | [On-policy self-distillation (OPSD)](https://arxiv.org/abs/2601.18734) や [TTRL](https://arxiv.org/abs/2605.19444) など、TTPOの基礎となる論文。 |
