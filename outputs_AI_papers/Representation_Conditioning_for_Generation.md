# Representation Conditioning for Generation

| 項目 | 内容 |
|---|---|
| どんなもの？ | 拡散モデル（Diffusion Transformer）の学習効率と生成品質を向上させる新しいアライメント手法RECON。既存手法REPAが学習後に廃棄していた投影ヘッド（projection head）を、推論時の条件付けとして再利用する手法です。 |
| 先行研究と比べてどこがすごい？ | REPAと比較して63倍高速に収束し、追加パラメータなしで推論時のサンプリングステップ数を大幅に削減できる点。学習済みモデルの資源を無駄にせず、より強力な意味的ガイダンスを推論時に活用可能にしました。 |
| 技術や手法のキモはどこ？ | 学習時に使用した投影ヘッドを捨てず、推論時に「ビジョンエンコーダの代理」として再利用する点。この投影ヘッドの出力をセマンティックトークンとして拡散モデルの後段層に注入することで、効率的に意味的情報を反映させます。 |
| どうやって有効だと検証した？ | ImageNet 256x256におけるgFIDスコアの評価や、テキストから画像生成（MS-COCO, BLIP3-o）での比較検証を実施。また、CKNNAや線形プローブによる中間層のセマンティクス分析、強ノイズからの復元実験を行い、その有効性を実証しました。 |
| 議論はある？ | セマンティックトークンを注入する際、学習と推論での条件のズレ（分布の乖離）が課題となる。現状は時間依存のスケジューリングで緩和しているが、モデルが本来持たない情報に頼りすぎるリスクや、さらなる最適化の余地がある。 |
