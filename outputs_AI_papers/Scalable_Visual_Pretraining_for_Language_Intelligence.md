# Scalable Visual Pretraining for Language Intelligence

| 項目 | 内容 |
|---|---|
| どんなもの？ | 科学技術文書の図表やレイアウト情報を保持したまま、視覚情報として直接学習する「Visual Pretraining (VP)」という手法。テキストへの変換過程で失われる構造的知識を視覚的特徴量としてモデルに深く統合し、言語知能の向上を図る。 |
| 先行研究と比べてどこがすごい？ | OCRやHTML解析によるテキスト抽出（情報損失を伴う）に依存せず、生の文書画像から直接学習する。テキストのみの事前学習と比較して、少ないトークン予算（25%）で高い推論精度を達成し、かつ明示的な画像・テキストペアのラベルなしでクロスモーダルな整合性を強化できる点。 |
| 技術や手法のキモはどこ？ | 文書画像を視覚的パッチとして処理し、空欄を除去した「疎な前景視覚シーケンス」を構築する点。これを次の視覚潜在表現を予測する自己回帰的なタスク（next visual latent prediction）としてLLMに学習させることで、モデル内に文書の幾何学的・構造的な知識を定着させている。 |
| どうやって有効だと検証した？ | Qwen3.5やLlama3.2 Vision等のバックボーンを用い、MMLU-ProやGPQA、AIMEなどの科学的推論ベンチマークで評価。さらに、文書の視覚的密度ごとの推論精度の変化や、潜在表現のクロスモーダル整合性（CKA、Mutual k-NN等）を測定し、TP（テキスト事前学習）を上回る結果を示した。 |
| 議論はある？ | 言語事前学習から完全に独立した手法ではなく、テキスト事前学習を補完・拡張するものと位置づけられる。また、現在の実験は科学的PDFのような知識密度の高い文書に限定されており、自然画像や動画などの広範な視覚コーパスに同様の戦略が通用するかは将来の課題。 |
