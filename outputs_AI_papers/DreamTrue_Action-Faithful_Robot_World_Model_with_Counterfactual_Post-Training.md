# DreamTrue: Action-Faithful Robot World Model with Counterfactual Post-Training

| 項目 | 内容 |
|---|---|
| どんなもの？ | ロボットの動作指示に対して、物理的に妥当かつ忠実な将来のビデオを予測するためのクロスエンボディメント（多様なロボット形態に対応した）世界モデル。カメラの校正ミスを修正し、反事実的なトレーニングを通じて、失敗例を含む多様な相互作用をシミュレーション可能にする。 |
| 先行研究と比べてどこがすごい？ | 既存データセットのカメラ校正誤差をオフラインで自動補正し、さらに失敗ケースを含む多様な動作データを人工的に生成する「反事実的ポストトレーニング」により、物理的な相互作用の妥当性を大幅に向上させた点。ロボットの実機追加収集なしで、未知の環境やロボット形態への汎化性能を実現している。 |
| 技術や手法のキモはどこ？ | ロボットのURDF（モデル情報）と記録された状態を用いてカメラパラメータを最適化する「オフライン幾何学的校正」と、生成された動画を評価する人間アノテーション済みの「身体性ビデオ報酬モデル」を用いた強化学習によるポストトレーニング。 |
| どうやって有効だと検証した？ | AgiBot benchmark等の複数のロボットデータセットで検証。行動追従性（nDTW）、物理的妥当性（欠陥率の削減）、およびシミュレータとしての政策評価の忠実度（成功率の予測精度）を既存手法と比較し、state-of-the-artの性能を達成した。 |
| 議論はある？ | 現在の手法は画像空間での推論に限定されているため、極端な遮蔽や視界の制限がある状況下では、視覚的には正しく見えても物理的に不正確な相互作用を生成する可能性がある点を課題として挙げている。 |
