# Vision as Unified Multimodal Generation

| 項目 | 内容 |
|---|---|
| どんなもの？ | コンピュータビジョンの多種多様なタスク（物体検出、セグメンテーション、幾何学的予測など）を、単一の統合マルチモーダルモデル（UMM）を用いた「汎用的な生成タスク」として定式化した研究。タスク固有のアーキテクチャを廃し、自然言語指示に従ってテキスト、画像、またはそれらの混合出力を生成することで、広範な視覚認識能力を実現した。 |
| 先行研究と比べてどこがすごい？ | 従来手法はタスクごとに固有の予測ヘッドが必要だったが、本手法は単一モデルで構造化データから密な幾何学予測までをシームレスに扱える。また、大規模な「SenseNova-Vision Corpus」を構築し、汎用的な生成能力を損なわずに専門的な視覚タスク能力を統合した点が優れている。 |
| 技術や手法のキモはどこ？ | コンピュータビジョンのアノテーションを、UMMが扱えるテキストと画像の生成目標に変換（例：箱座標をテキスト生成、深度やマスクを画像生成）し、学習データとして「SenseNova-Vision Corpus」を構築した点。さらに、タスク固有の構造を保持しつつ、標準的な交差エントロピー損失とRectified-Flow目的関数を用いて混合学習を行った点。 |
| どうやって有効だと検証した？ | 構造化認識（検出・OCR等）、密な幾何学予測（深度・法線）、セグメンテーション、マルチビュー3Dの4つのファミリーにおいて、既存の専門特化型システムや汎用ビジョンモデルと比較検証を実施。定量的評価に加え、言語による柔軟なタスク指定（Visual Grounded Segmentation等）の定性的なデモンストレーションも行った。 |
| 議論はある？ | まだ専門特化型モデル（SAM等）の方が高い精度を出すタスクがあること、複雑なシーンでは学習データへの依存や推論の改善余地があること。また、現在のモデルは画像生成ベースの事前学習に依存しており、さらなるスケーリングやビデオ領域への拡張が今後の課題として挙げられている。 |
