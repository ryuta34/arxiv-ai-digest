# PhiZero: A World Model Built Around Physical Language

| 項目 | 内容 |
|---|---|
| どんなもの？ | 物理世界の進化パターンを「物理言語（Physical Language）」というコンパクトな離散表現として学習し、それに基づいて将来の動画を生成する世界モデル「PHIZERO」を提案した研究。推論（Reason）してからレンダリング（Render）するパラダイムを採用し、物理的な整合性とインタラクティブな制御を実現している。 |
| 先行研究と比べてどこがすごい？ | 画素空間で直接将来を予測する手法と異なり、物理的な状態遷移を独立した言語的空間で明示的に推論するため、複雑な物理現象の予測において高い忠実度と整合性を誇る。また、クロスモーダルな転移やゼロショットの動作転移にも柔軟に対応可能である。 |
| 技術や手法のキモはどこ？ | 1. 物理言語トークナイザーによる状態遷移の離散表現化。2. プレトレーニングされたVLMを活用した「物理言語推論器」による将来の遷移予測。3. 物理言語と最初のフレームを条件として動画を生成する「Reason-then-Render」パラダイムの導入。 |
| どうやって有効だと検証した？ | 「Physics-IQ Verified」「PhyGround」「WorldModelBench」などの物理動画生成・理解ベンチマークで性能を評価し、競合モデルを上回る物理的忠実性と整合性を実証した。さらにロボット制御や自律走行のシナリオで、インタラクティブかつ制御可能な世界モデルとしての有効性を示した。 |
| 議論はある？ | 現在の物理言語は、記号的な物理法則ではなく観察データに基づく経験的な表現である点。また、学習は視覚情報に依存しているため、触覚や微細な粒子力学など、視覚的に曖昧な遷移のモデル化には課題がある。今後は、より長期間の予測や多様なデータの取り込みが求められる。 |
| 次に読むべき論文は？ | 関連手法として、物理的な推論を組み込んだ「[PhyGround (Lin et al., 2026)](https://arxiv.org/abs/2605.10806)」や、物理的一貫性を重視した「[Physics-IQ Verified (Rädsch et al., 2026)](https://arxiv.org/abs/2606.18943)」が挙げられる。 |
