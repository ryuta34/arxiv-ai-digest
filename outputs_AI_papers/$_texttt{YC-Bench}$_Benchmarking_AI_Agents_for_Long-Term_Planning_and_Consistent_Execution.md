# $\texttt{YC-Bench}$: Benchmarking AI Agents for Long-Term Planning and Consistent Execution

| 項目 | 内容 |
|---|---|
| どんなもの？ | 大規模言語モデル（LLM）エージェントの長期的な計画立案と一貫した実行能力を評価する、スタートアップ運営をシミュレーションする新しいベンチマーク「YC-Bench」を提案した論文。エージェントは数百ターンにわたり、タスク選択、リソース配分、敵対的クライアントへの対応を行い、最終的な収益で評価される。 |
| 先行研究と比べてどこがすごい？ | 従来のベンチマーク（PlanBench等）が単発の推論や限定的なシミュレーションに留まるのに対し、本手法は市場の変動や隠れた敵対的クライアント、報酬とコストの長期的な複合的力学を導入した点。また、記憶保持のためのスクラッチパッド使用を必須とし、長期的な戦略的一貫性をより厳格に評価できる点。 |
| 技術や手法のキモはどこ？ | 部分観測マルコフ決定過程（POMDP）に基づくシミュレーション環境において、対話履歴の切り捨て（20ターン）をあえて行うことで、エージェント自ら「スクラッチパッド」を使って重要な情報を保持する動的な記憶戦略を促す設計。 |
| どうやって有効だと検証した？ | GPT-5.4、Claude Opus 4.6、GLM-5など12種類の最新モデルを対象に、各3シードで計36回の評価実験を実施。最終的な資本収益率、敵対的クライアントの識別率、スクラッチパッドの活用状況、およびAPIコストあたりの利益（コスト効率）を比較した。 |
| 議論はある？ | 多くのモデルで「推論と実行の乖離（正しい戦略を立案しても、実際の行動に移せない）」が見られた。また、コンテキストウィンドウのサイズ変更実験から、単純にウィンドウを広げても必ずしも性能向上にはつながらず、過度な拡張は効率を低下させる可能性があると指摘している。 |
