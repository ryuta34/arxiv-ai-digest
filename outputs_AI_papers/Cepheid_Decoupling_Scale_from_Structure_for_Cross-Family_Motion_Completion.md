# Cepheid: Decoupling Scale from Structure for Cross-Family Motion Completion

| 項目 | 内容 |
|---|---|
| どんなもの？ | 骨格やメッシュの対応関係なしに、スパースな頂点変位からメッシュ全体の詳細な運動を推定する手法CEPHEID。物理的なスケールを学習から切り離し、未知の形状カテゴリにも汎用的に適応できる手法。 |
| 先行研究と比べてどこがすごい？ | カテゴリごとに事前学習が必要だった先行研究とは異なり、単一のモデルで未知のカテゴリ（布や脚付きロボット）へゼロショット転移可能。また、物理的な振幅のばらつきを克服し、従来手法（調和拡張）を全評価カテゴリで上回る精度を実現した点。 |
| 技術や手法のキモはどこ？ | 残差運動を「幾何学的な構造」と「物理的なスケール（振幅）」に分解し、スケールを観測データから動的に推定するアルゴリズムを導入した点。また、調和拡張をベースラインとして学習を効率化し、フローマッチングを用いて次元のない残差事前分布を学習した点。 |
| どうやって有効だと検証した？ | 5つの多様なカテゴリ（DT4D、AMASS、Franka、布、脚付きロボット）を用いて、0.5%〜50%のスパースな観測条件下で検証。定量評価として調和拡張をベースラインとした相対誤差を測定し、実用的なロボットのproprioceptionやビデオからの点追跡によるアプリケーションでも有効性を確認。 |
| 議論はある？ | 現在の評価は正確な頂点変位を前提としており、センサーノイズやオクルージョン、深度歪みといった実環境での課題に対する評価が今後の課題。また、特定の固定されたセンサー配置ではファインチューニングが有効であることなど、適応性の限界も示唆されている。 |
