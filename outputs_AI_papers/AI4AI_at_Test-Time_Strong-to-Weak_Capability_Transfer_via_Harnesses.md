# AI4AI at Test-Time: Strong-to-Weak Capability Transfer via Harnesses

| 項目 | 内容 |
|---|---|
| どんなもの？ | 強いモデル（ビルダー）が、弱いモデル（ターゲット）の推論環境を改善する「inference-time harness（推論時ハーネス）」を構築する「Strong-to-Weak Scaffolding」という手法を提案した論文。ターゲットモデルのパラメータを更新することなく、外部的な構造やルールによって、推論能力を大幅に引き上げることを目的としている。 |
| 先行研究と比べてどこがすごい？ | 従来のモデル蒸留（distillation）が必要としていたモデルの再学習（パラメータ更新）を必要とせず、推論時に実行環境を最適化するだけで、弱いモデルを劇的に高性能化できる点。GPT-5.4-miniの平均精度を0.49から0.91まで向上させ、一部のタスクでは人間が設計したハーネスを超える性能を達成した。 |
| 技術や手法のキモはどこ？ | タスクの構造的な特徴をルールベースやプログラムで処理する「Deterministic Offloading（決定的オフロード）」と、厳格な回答フォーマットの強制やタスクルーティングなどを組み合わせ、ターゲットモデルの認知的負荷を徹底的に削減した点。 builderモデルが少量の検証セットを用いて試行錯誤し、最適な環境（プロンプト、ツール、コード）を構築する。 |
| どうやって有効だと検証した？ | 4つの代表的なTheory-of-Mind（心の理論）ベンチマーク（BigToM, Hi-ToM, MMToM-QA, MuMA-ToM）を用い、計72の実験を実行。ターゲットモデルのベースライン性能と比較し、安定性、検証効率、スケーラビリティ、認知負荷軽減の効果を多角的に検証した。 |
| 議論はある？ | タスクの構造が明確で「ルール化可能な」タスクには有効だが、深層的な推論が必要な箇所では限界がある。また、強力すぎるターゲットモデルに対しては、過度なハーネスが逆に推論を阻害する「オーバー・スキャフォールディング」のリスクがあることが示された。 |
