# AVISE: Framework for Evaluating the Security of AI Systems

| 項目 | 内容 |
|---|---|
| どんなもの？ | AIシステムの脆弱性を特定・評価するための、モジュール式オープンソースフレームワーク「AVISE」を提案した論文。AIモデルを標的とした自動化されたセキュリティ評価テスト（SET）の開発・実行を可能にする。 |
| 先行研究と比べてどこがすごい？ | 既存のツールが特定のモデルや攻撃に特化していたのに対し、AVISEはモジュール設計により拡張性が高く、ブラックボックス・グレーボックス・ホワイトボックスの評価が可能。また、AIの確率的挙動を考慮し、統計的集約に基づいた評価を行う点を特徴とする。 |
| 技術や手法のキモはどこ？ | オーケストレーション層（テストの実行管理）と相互作用層（ターゲットシステムとの通信）から構成されるフレームワーク。さらに、敵対的言語モデル（ALM）を導入して多段階の脱獄攻撃（Red Queen攻撃）を自動化し、別の評価用言語モデル（ELM）で結果を判定する仕組み。 |
| どうやって有効だと検証した？ | 9つの最新オープンソースLLMを対象にRed Queen攻撃を実行し、ALMによる増強版と非増強版で比較。ELMの判定能力を評価し、精度92%、F1スコア0.91、MCC 0.83という高い性能を確認した。 |
| 議論はある？ | AIセキュリティの進化が速いため、フレームワークですべてのセキュリティ評価を完結させるのは困難。また、ELMの判定における偽陽性・偽陰性の可能性や、赤軍演習用ツールが悪用される可能性という二重利用のジレンマについても言及している。 |
