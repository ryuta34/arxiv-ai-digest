# Visual Preference Optimization with Rubric Rewards

| 項目 | 内容 |
|---|---|
| どんなもの？ | 視覚言語モデル（VLM）のファインチューニングにおける、インスタンス固有のルーブリック（評価基準）を用いた効率的かつ詳細な選好データ構築手法「rDPO」の提案。モデルが生成した回答に対して、チェックリスト形式の基準でフィードバックを行うことで、微細な視覚推論能力の向上とハルシネーションの低減を目指す。 |
| 先行研究と比べてどこがすごい？ | 従来手法が固定テンプレートや粗い報酬モデルに依存していたのに対し、画像と指示ペアごとに動的に生成される「インスタンス固有のルーブリック」を用いることで、より粒度の細かい判断を可能にした。結果として、30B-A3B規模のオープンソースモデルの判断精度をGPT-5.4に近いレベルまで引き上げることに成功している。 |
| 技術や手法のキモはどこ？ | モデル非依存の「指示-ルーブリックプール」をオフラインで構築し、それをオンポリシーなデータ収集プロセスで再利用する点。各基準を「必須（Essential）」と「追加（Additional）」に分類し、厳格な質的差分に基づいて選好ペアをマイニングするパイプラインが核心である。 |
| どうやって有効だと検証した？ | 報酬モデルの性能（MM-RBやVA-B等のベンチマーク）、手法の有効性確認（AI2D等でのフィルタリング比較）、および大規模な社内ベンチマークでのスケーリング性能を評価。Outcome-based（結果ベース）のフィルタリングよりも高い性能を示し、ベースモデルを明確に上回ることを実証した。 |
| 議論はある？ | 現在の手法はルーブリックフィードバックをオフラインのデータ構築に用いており、フィードバックが最適化ループ外に存在する点。今後はルーブリックに基づいた報酬をモデルの学習ループに直接組み込む（オンライン訓練化）ことが重要であり、Group Relative Policy Optimization (GRPO) 等への拡張が将来課題として挙げられている。 |
