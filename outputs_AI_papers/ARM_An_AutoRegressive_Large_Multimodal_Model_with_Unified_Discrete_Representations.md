# ARM: An AutoRegressive Large Multimodal Model with Unified Discrete Representations

| 項目 | 内容 |
|---|---|
| どんなもの？ | 画像の理解、生成、編集を単一の次トークン予測フレームワーク内で統一した、離散表現ベースの自己回帰型マルチモーダルモデル「ARM」。高精度なセマンティック視覚トークナイザーと強化学習による選好アライメントにより、理解性能を維持しつつ高品質な生成・編集を実現する。 |
| 先行研究と比べてどこがすごい？ | 従来のモデルが理解と生成のために異なる視覚エンコーダーを使い分け、計算コスト増やモデルの断片化を招いていたのに対し、本手法は単一の離散視覚表現で統一した。また、離散トークン空間での強化学習により、生成と編集のタスク間で相互に性能を高める「クロスタスクシナジー」を実証した点。 |
| 技術や手法のキモはどこ？ | 1) 4つの目的関数（キャプション、画素再構成、Sigmoid対照学習、特徴蒸留）を用いて、意味判別性と詳細再現性を両立させた視覚トークナイザー。2) グループ相対方策最適化（GRPO）を用い、画像生成と編集の選好に合わせた強化学習を行い、マルチモーダル理解能力を低下させずに生成品質を向上させた点。 |
| どうやって有効だと検証した？ | 視覚理解（POPE, MMMU等）、テキストからの画像生成（GenEval, DPG, WISE）、指示に基づいた画像編集（GEdit-Bench）など多岐にわたるベンチマークで評価を実施。既存の連続表現ベースのモデルや先行する離散モデルと比較し、同等以上の性能を達成した。 |
| 議論はある？ | セマンティックトークナイザーと画素再構成のトレードオフや、強化学習による生成品質向上の詳細を分析。現状ではデコーダーの性能に依存する部分があり、完全な自律的な視覚生成にはさらなるアーキテクチャの洗練が求められる。 |
