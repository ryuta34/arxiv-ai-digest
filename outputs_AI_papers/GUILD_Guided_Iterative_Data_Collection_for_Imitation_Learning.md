# GUILD: Guided Iterative Data Collection for Imitation Learning

| 項目 | 内容 |
|---|---|
| どんなもの？ | ロボットの模倣学習において、ターゲット環境への適応を最大化するために、どのデータを収集すべきかを能動的に決定する「GUILD」というフレームワーク。VLM（Vision-Language Model）によるタスク提案と、予測的データアトリビューションによるユーティリティ評価を組み合わせた反復的な枠組みである。 |
| 先行研究と比べてどこがすごい？ | 既存のデータキュレーション手法が「収集後のデータ選別」に留まるのに対し、GUILDはデータ収集プロセス自体を最適化する。また、計算コストの高い手法（Factored Scaling Curvesなど）と比較し、単一のポリシー学習から得られるデータアトリビューション信号を用いて効率的に収集戦略を導出できる点が優れている。 |
| 技術や手法のキモはどこ？ | VLMを用いてターゲット環境に関連するタスクの分布を提案し、その各タスクから得られるデータが下流のポリシー性能にどの程度寄与するかを、データアトリビューション（MAGICなど）を用いて推定する。このスコアをフィードバック信号として、データ収集の予算を最も有益なタスクへ動的に再配分するループ構造。 |
| どうやって有効だと検証した？ | LIBEROベンチマーク（シミュレーション）および6つの実環境ロボット実験において検証。ランダム収集や従来のデータキュレーション手法、さらには専門的なロボットエンジニアによる収集戦略と比較し、同等のデータ予算で一貫して高い成功率とサンプル効率を達成することを示した。 |
| 議論はある？ | VLMが不適切なタスクを提案するリスクがあり、微弱な人間の監督が必要な場合がある。また、データ評価（アトリビューション）とデータ収集の反復には計算コストがかかる。現在はタスク空間をVLMのプロンプトで離散化しているが、連続的なパラメータ探索への拡張が今後の課題。 |
