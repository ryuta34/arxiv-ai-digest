# When Should We Intervene at Test Time?

| 項目 | 内容 |
|---|---|
| どんなもの？ | デプロイされたAIモデルにおいて、入力データが時間変化する際に、どのテスト時適応（介入）をいつ適用すべきかを判断するコントローラー「PORTAL」を提案。限られたラベル予算を用いて、複数の適応手法（候補）の精度を比較し、最善の手法を動的に選択する。 |
| 先行研究と比べてどこがすごい？ | 従来の適応手法はバッチ単位の統計更新などで性能を改善する一方、適用タイミングを誤るとかえって精度を悪化させるリスクがあった。PORTALは「ラベルをいつ、どの入力に付与し、いつクエリを停止すべきか」を最適化することで、介入の失敗を防ぎつつ、少ないラベルコストで精度向上を最大化できる点。 |
| 技術や手法のキモはどこ？ | 全ての候補手法を同じ入力に対して共通のラベルで評価し、その結果から精度差と不確実性を推定する点。ラベル付与を「どの候補が現在のリーダーを追い越せるか」という比較に集中させ、ラベル付与による精度向上期待値がコストを下回る場合に停止する「局所的停止ルール」を導入したこと。 |
| どうやって有効だと検証した？ | PACS、ImageNet-C、CIFAR-10-C/100-Cなどの多様なドメインシフト環境で検証。特に、クラス構成が偏る「クラスブロック到達」環境において、単一の固定適応手法では精度が激減するところを、PORTALが適切に選択を切り替えることで大幅な精度低下を防ぐことを示した。 |
| 議論はある？ | 過去のラベル統計に依存するため、ストリームの性質が激変した際に過去の証拠が適応できない場合がある。これに対処するために周期的ラベルチェックや履歴の減衰などの工夫をしているが、ストリームの非定常性の強さには制約がある。 |
