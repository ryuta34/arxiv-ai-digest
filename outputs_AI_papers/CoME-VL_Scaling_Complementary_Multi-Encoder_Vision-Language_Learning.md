# CoME-VL: Scaling Complementary Multi-Encoder Vision-Language Learning

| 項目 | 内容 |
|---|---|
| どんなもの？ | 視覚エンコーダの特性（セマンティクスと空間解像度）に着目し、複数のエンコーダから情報を適切に融合するマルチエンコーダ視覚言語モデル（VLM）フレームワーク「CoME-VL」。SigLIP2（意味理解）とDINOv3（空間的接地）の補完的な特徴を抽出し、効率的な視覚言語学習を実現する。 |
| 先行研究と比べてどこがすごい？ | 従来の手法では、単一エンコーダによる情報欠落や、単純な連結によるトークン負荷の増大が課題であった。本手法は、エントロピーに基づいた層選択と直交性制約により、冗長性を抑えつつ視覚接地タスク（点描、計数、検出）で大幅な性能向上（平均+4.9〜5.4%）を達成した点。 |
| 技術や手法のキモはどこ？ | ①エントロピーに基づきエンコーダ層の重要度を評価・選択する層選択手法、②冗長性を排除する「直交正則化マルチレイヤー混合」、③空間的対応を維持しつつトークン数を削減する「RoPE強化型クロスアテンション」の3点。 |
| どうやって有効だと検証した？ | PixMoベンチマーク（チャート、図表、表、その他、計数、点描）およびRefCOCOデータセットを用いて評価。従来モデル（Molmo等）との比較で、特にファイングレインな接地タスクにおいて一貫した性能向上を実証した。 |
| 議論はある？ | 複数のエンコーダを組み合わせるため、単一エンコーダモデルと比較してわずかな推論時間の増加（1.26s→1.52s）が生じる。ただし、単純なトークン連結を行う手法（COMM等）よりは効率的である。 |
