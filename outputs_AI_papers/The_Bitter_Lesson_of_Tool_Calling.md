# The Bitter Lesson of Tool Calling

| 項目 | 内容 |
|---|---|
| どんなもの？ | 大規模言語モデル（LLM）のツール呼び出しにおいて、従来のJSON形式ではなく、Pythonスクリプトによるプログラム的なツール呼び出し（PTC）の有効性を体系的に評価した研究。14のモデルを用いて、精度、並列実行、コンテキスト負荷への耐性を検証した。 |
| 先行研究と比べてどこがすごい？ | 従来のツール呼び出しベンチマークがJSON形式に偏っていたのに対し、実行可能コードを用いた手法を、モデル世代や多様な実環境タスク条件下で包括的に比較した点。特定のモデル系列ではなく、モデル世代が手法の適応能力に寄与することを明らかにした。 |
| 技術や手法のキモはどこ？ | モデルに対し、型付きのPythonスタブを含むシステムプロンプトを与え、単一のシェルサブプロセス内で実行可能なPythonスクリプトを書かせる点。これにより、複数ターンを要する連鎖的なタスクや、高い並列負荷（ファンアウト）を単一ステップで処理可能にした。 |
| どうやって有効だと検証した？ | BFCL v4ベンチマークの309エントリを用いて、14のモデルで検証。連鎖（Chaining）、並列化（Parallelism）、コンテキスト汚染（Context rot）の3つのアブレーション研究を行い、JSON形式と比較した。 |
| 議論はある？ | 精度はモデル世代に依存しており、古いモデルの一部では改行コードの処理失敗といった実装上の課題がある。また、PTCは固定のトークンオーバーヘッドを持つため、小規模なタスクではコスト高になる可能性がある。 |
