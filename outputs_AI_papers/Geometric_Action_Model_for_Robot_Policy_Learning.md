# Geometric Action Model for Robot Policy Learning

| 項目 | 内容 |
|---|---|
| どんなもの？ | ロボット操作のための言語条件付きマニピュレーションポリシー「Geometric Action Model (GAM)」を提案した論文。既存のGFM（幾何学的基盤モデル）の構造を再利用し、認識・未来予測・行動デコードを単一のバックボーンで統合することで、高い堅牢性と高速な推論を実現した。 |
| 先行研究と比べてどこがすごい？ | 2D画像のみに依存する従来のVLAと異なり、明示的な3D幾何学的知識を組み込むことで、環境変化やカメラ視点の摂動（Perturbation）に対して極めて高い堅牢性を誇る。また、推論速度が大幅に向上（既存の拡散モデル比で最大55倍高速）しており、実用性が極めて高い。 |
| 技術や手法のキモはどこ？ | 既存のGFMの中間層を分割し、その間に言語・固有受容感覚・行動履歴を条件とした「因果的未来予測器（Causal Future Predictor）」を挿入した点。これにより、未来の幾何学的状態（3D潜伏空間）と行動を同時に autoregressiveに生成・伝播させる設計となっている。 |
| どうやって有効だと検証した？ | LIBEROおよびLIBERO-Plusベンチマーク（カメラ視点、照明、背景等の摂動環境）でのシミュレーション実験、および実機ロボットによる4つのマニピュレーションタスク（Pick and place等）を通じた評価を実施。いずれにおいても既存の強力なベースラインを上回る成功率を達成した。 |
| 議論はある？ | 言語推論能力と常識的推論能力は、凍結されたテキストエンコーダーの性能に依存しており、限界がある。今後の発展として、大規模言語モデル（LLM）や外部の推論モジュールの統合を挙げている。 |
