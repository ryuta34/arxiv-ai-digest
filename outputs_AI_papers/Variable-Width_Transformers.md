# Variable-Width Transformers

| 項目 | 内容 |
|---|---|
| どんなもの？ | Transformerの各層の幅を一定にする標準的な設計に対し、層によって幅を変化させる（非一様にする）手法「><former」を提案。×字型の構造（初期と末尾が広く、中間が狭い）を採用することで、計算効率と性能を両立した言語モデル。 |
| 先行研究と比べてどこがすごい？ | 従来は全層で一定の計算予算を割り当てていたが、本手法はモデルの容量を深さ方向に適切に再配分することで、パラメータ数を固定したまま、従来の一定幅モデルと比較して損失（パープレキシティ）を改善しつつ、FLOPs（訓練コスト）とKVキャッシュメモリ使用量を削減した点。 |
| 技術や手法のキモはどこ？ | パラメータフリーな残差リサイズメカニズムを導入し、層ごとに異なる隠れ次元数（幅）を実現した点。また、固定された広さの残差ストリームを用い、層ごとの幅に応じて特定のスライスのみを読み書きし、未使用次元はコピーして飛ばす設計により、効率的な情報伝達と容量の有効活用を可能にした。 |
| どうやって有効だと検証した？ | 200Mから2Bのパラメータを持つモデルおよびMoEモデルをDCLMデータセットで学習させ、言語モデリング損失および各種NLP下流タスクで比較評価。さらに、ロジットレンズ解析や行列エントロピー解析、活性化密度の分析を通じて、中間層の表現崩壊が抑制されていることを示した。 |
| 議論はある？ | 実装上の複雑さ（異なる層幅に対応するためのカーネル最適化が必要）や、標準的なテンソル・パイプライン並列化との相性、および特定のハードウェア上での実装負荷が現在の課題。現在は計算インフラが一定幅モデルに最適化されていることがボトルネックであると指摘。 |
