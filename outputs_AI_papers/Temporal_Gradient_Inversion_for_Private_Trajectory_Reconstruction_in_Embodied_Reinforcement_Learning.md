# Temporal Gradient Inversion for Private Trajectory Reconstruction in Embodied Reinforcement Learning

| 項目 | 内容 |
|---|---|
| どんなもの？ | エンボディド強化学習エージェントが学習時にサーバーへ送信する勾配から、エージェントが環境内で経験した観測画像や行動の履歴（軌跡）を復元する攻撃手法「TRACE」を提案した論文。送信される勾配が時系列的な相関を持つことに着目し、これを悪用することで高精度な軌跡の再構築を実現している。 |
| 先行研究と比べてどこがすごい？ | 従来手法が個々の勾配を独立したものとして扱い単一フレームの復元に留まっていたのに対し、時系列の勾配データをまとめて扱うことで相関を利用し、再構築精度を大幅に向上させた点。また、最適化ベースの既存手法よりも数桁高速（ミリ秒単位）で復元が可能である。 |
| 技術や手法のキモはどこ？ | 勾配を符号化する「勾配エンコーダ」、時系列のコンテキストを保持・伝播させる「因果Transformer」、そしてそれらから観測画像と行動を同時に復元する「デコーダ」の3段構成。また、ポリシーヘッドの勾配構造を利用した「閉形式の行動復元」の理論的証明も行っている。 |
| どうやって有効だと検証した？ | AI2-THORシミュレーターを用いたポイントゴールナビゲーション環境で、PPOやA2Cといった主要な強化学習アルゴリズムに対して検証。最適化ベース手法やLtIベースラインとの比較でPSNRやSSIM等の指標を改善し、量子化や剪定（プルーニング）などの一般的な勾配防衛策に対する脆弱性も示した。 |
| 議論はある？ | 現在は離散的な行動空間を想定しており、連続的な行動空間への拡張は今後の課題。また、DP-SGDなどの強力なプライバシー防衛策には一定の耐性があることを確認しているが、計算コストと利便性のトレードオフが重要であると指摘している。 |
