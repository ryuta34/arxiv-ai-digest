# SimWAM: A Simple World Action Model for End-to-End Autonomous Driving

| 項目 | 内容 |
|---|---|
| どんなもの？ | 自動運転におけるエンドツーエンドの計画生成のための、シンプルかつ効率的な「世界・行動モデル（WAM）」である。学習時には動画生成を補助信号として利用し、推論時には動画生成を排除して直接軌道を予測するアーキテクチャを採用している。 |
| 先行研究と比べてどこがすごい？ | 従来のWAMが抱えていた推論時の動画生成による高い遅延という課題を、推論時に動画ブランチを完全に削除することで解決した。また、学習後のモデルにおいて動画生成器の交換やスケーリングが容易であり、NAVSIMベンチマークで高いPDMSスコア（91.5）を達成しつつ、極めて低いレイテンシを実現した点。 |
| 技術や手法のキモはどこ？ | 動画生成モデルと行動計画モデルを「独立したアテンションマスク」で分離して学習させる点。これにより、行動予測が将来のフレームに依存せず、推論時には軽量な行動専門モデルのみを保持することが可能となった。さらに、強化学習（Flow-GRPO）を用いて直接的な運転品質の最適化を図った点。 |
| どうやって有効だと検証した？ | NAVSIMベンチマークおよびnuScenesデータセットを用いた実験により評価。他の最先端WAMベースの手法と比較し、高い計画精度を維持しながらレイテンシが大幅に低いことを示した。また、アブレーションスタディにより、各構成要素（動画共学習、強化学習、分離型マスク）の貢献度を検証した。 |
| 議論はある？ | 動画生成の品質が間接的に行動予測の質に影響するため、動画モデルの選択が重要である。現在は強化学習によりPDMSを向上させているが、強化学習の導入に伴う学習の不安定性や、特定の評価環境以外での一般化性能についてはさらなる検討の余地がある。 |
