# φ-RIE: From Photorealistic Reconstruction to Interactive Environments

| 項目 | 内容 |
|---|---|
| どんなもの？ | 3D Gaussian Splatting（3DGS）で再構成された実世界のシーンを、物理的なインタラクションが可能なシミュレーション環境へ変換するパイプライン「ϕ-RIE」です。シーン内の物体を個別に操作可能なアセットとして分離し、同時に背景の欠損部分を補完することで、フォトリアルな環境でのロボットシミュレーションを可能にします。 |
| 先行研究と比べてどこがすごい？ | 従来の再構成手法では、物体と背景が視覚的に絡み合っており物理シミュレーションに不向きでしたが、本手法は物体の分離、背景の補完、物理状態との同期を「結合（Coupled）」して行うことで、視覚的忠実度と物理的実行可能性を両立させた点に新規性があります。 |
| 技術や手法のキモはどこ？ | 「Coupled Scene Construction」という手法です。単一の物体識別情報を利用して、アセット生成・登録、ソースとなるガウス成分の除去、背景の補完を連動させることで、矛盾のないシミュレーション環境を構築します。また、シミュレータの物理状態と視覚的なガウス分布を整合させる仕組みも特徴です。 |
| どうやって有効だと検証した？ | 50のScanNet++シーンを使用し、計1,871件の物体リクエストに対して、候補の保持率、幾何学的な精度（F1スコア、Chamfer距離）、RoboCasa環境でのロボット操作成功率を評価しました。また、各コンポーネント（生成器、インペインティング等）の性能比較を実施しています。 |
| 議論はある？ | 現在の手法では、物理的な複雑な関節構造や変形可能オブジェクトには対応しておらず、また局所的な平面補完を行っているため、完全に隠れた部分の再現には限界があります。物理ロボットへの直接転送の難しさも課題として挙げられています。 |
