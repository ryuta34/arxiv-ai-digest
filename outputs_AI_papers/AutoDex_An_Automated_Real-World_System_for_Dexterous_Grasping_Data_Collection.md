# AutoDex: An Automated Real-World System for Dexterous Grasping Data Collection

| 項目 | 内容 |
|---|---|
| どんなもの？ | 多数の物体に対する多指ハンドの器用な把持操作を、自動かつ大規模に収集・ラベル付けする実世界データ収集システム「AutoDex」。人手介入なしの試行、自動ラベル付け、および安定的な物体配置リセットを統合し、実世界での把持データを効率的に蓄積する。 |
| 先行研究と比べてどこがすごい？ | 従来のテレオペレーション（人手操作）が抱える低速・疲労・バイアスという課題を克服し、シミュレーションでは不可能な「実世界での接触物理」を反映したデータを自動で生成できる点。テレオペ比で4.8倍の効率を達成し、成功率も大幅に向上させている。 |
| 技術や手法のキモはどこ？ | (1) 20台のカメラを用いた高密度な物体姿勢推定・追跡、(2) 実環境での成功・失敗を判定する自動リフト・アンド・ホールドラベル付け、(3) 接触回避とロボット保護のための学習済み残差トルクモニター、(4) 次の試行に向けて物体を自動再配置するリセットモジュール。 |
| どうやって有効だと検証した？ | 100種類の物体を用い、合計3,593回の把持試行を収集。テレオペレーションとのスループット比較や、シミュレーション上のモデル選別のみを行った場合との実世界成功率比較、およびカメラ密度が姿勢推定精度に与える影響などを定量的に評価した。 |
| 議論はある？ | 現在は固定されたアーム・ハンド構成における安定把持に限定されており、両手操作や動的な指の動きを伴う操作には対応していない。また、依然としてマルチカメラを備えたワークセル環境に依存する点が課題。 |
