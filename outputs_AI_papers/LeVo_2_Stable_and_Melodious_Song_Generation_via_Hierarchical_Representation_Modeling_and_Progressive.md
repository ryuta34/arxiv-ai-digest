# LeVo 2: Stable and Melodious Song Generation via Hierarchical Representation Modeling and Progressive Post-Training

| 項目 | 内容 |
|---|---|
| どんなもの？ | 楽曲生成における「グローバルな構造の整合性」と「トラックごとの音響的な詳細さ」の両立を目指した、ハイブリッドLLM-Diffusionフレームワーク。階層的な表現学習と、審美性を基準とした段階的なポストトレーニング（SFTおよびDPO）により、高品質なフルレングスの楽曲生成を実現する。 |
| 先行研究と比べてどこがすごい？ | 従来の混合トークンモデル（構造は良いが詳細に欠ける）やデュアルトラックモデル（詳細は良いが構造に欠ける・シーケンスが長すぎる）の欠点を、階層型アーキテクチャで解消した点。また、自動音楽審美評価に基づく段階的な学習戦略により、報酬ハッキングを防ぎつつ、人手による選好と高い整合性を両立している。 |
| 技術や手法のキモはどこ？ | 1. 混合セマンティックLM（全体構造）とトラック特化型LM（詳細な音響）を分けた階層型推論、2. 自動音楽評価フレームワークを導入した審美性重視の3段階学習（事前学習・段階的ポストトレーニング・モジュール拡張）、3. 擬似オンライン手法を含む прогрессивный（逐次的）なDPO最適化。 |
| どうやって有効だと検証した？ | 20名の専門家による6つの定性的指標（音楽性、メロディ、編曲等）に基づくMOS評価と、楽曲データを用いたGemini評価による定量分析（歌詞整合性、感情、楽器分類精度など）を、既存のオープンソースモデルや主要な商用サービス（Suno v5等）と比較。 |
| 議論はある？ | 学習データの質やアノテーションのノイズに依存しており、現時点では最高峰のクローズドソース（商用モデル）と比べると、ジャンルや楽器制御の面でわずかに及ばない部分がある。今後は注釈付きデータの精度向上や、より多様なプロンプトへの対応が課題。 |
