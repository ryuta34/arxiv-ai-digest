# Handover of In-Context Learning State Across Session Boundaries

| 項目 | 内容 |
|---|---|
| どんなもの？ | 大規模言語モデルを用いたアプリケーションにおいて、セッションの境界（文脈制限や再起動など）を跨いでタスクを継続する際の「セッションハンドオーバー」を定式化した研究。限られたメモリ容量の中で、タスクの継続に必要な情報をいかに効率的に保持・継承するかという理論的枠組みを提案している。 |
| 先行研究と比べてどこがすごい？ | 従来のプロンプト圧縮が「特定のクエリ」を前提としていたのに対し、本研究は「クエリが未知の段階」で情報を記録する必要があるというハンドオーバー特有の制約をモデル化した。統計的十分性やベイズ決定理論を用いて、情報保持と損失の関係を理論的に導出した点が新しい。 |
| 技術や手法のキモはどこ？ | タスクの目標や制約を直接記録する部分（Hexact）、タスク損失に対する明示的な保証を持つ統計量を用いた部分（Hstat）、重要度の高い残余観測（Hresidual）の3部構成で記録を構築する手法。また、ガウス線形回帰やノンパラメトリック回帰におけるメモリ容量と予測リスクのトレードオフを理論的に特定した。 |
| どうやって有効だと検証した？ | ガウス線形回帰において有限次元の十分統計量を用いたハンドオーバーの有効性を示し、ノンパラメトリック回帰においてメモリ制限下でのミニマックスリスクの上下限を導出することで、提案手法の理論的妥当性を評価した。 |
| 議論はある？ | 実務上の限界として、モデルやトークナイザーの依存関係、シリアル化に伴う情報損失の分離の難しさを挙げている。また、動的なタスクにおいて情報量がどう変化するかや、予測の不確実性とメモリ予算の間のより詳細な関係が今後の課題である。 |
