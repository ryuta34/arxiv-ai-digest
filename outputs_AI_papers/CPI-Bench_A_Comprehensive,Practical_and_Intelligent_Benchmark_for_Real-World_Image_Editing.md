# CPI-Bench: A Comprehensive,Practical and Intelligent Benchmark for Real-World Image Editing

| 項目 | 内容 |
|---|---|
| どんなもの？ | 画像編集モデルの性能を包括的・実用的に評価するための新しいベンチマーク「CPI-Bench」を提案。基本性能、実用的な展開能力、推論を要する高度な編集能力の3つの観点からモデルを評価する。 |
| 先行研究と比べてどこがすごい？ | 既存のベンチマークが単一画像タスクに限定され、性能が飽和していたのに対し、本手法は複数画像編集や複雑な推論を伴う実用的なタスクを導入。モデル間の性能差を明確化し、人間の評価基準と高い相関を示す。 |
| 技術や手法のキモはどこ？ | タスクを「General」「Practical」「Intelligent」の3階層に分類し、VLM（Vision-Language Model）を活用した評価パイプラインを構築。顔の匿名化処理などの倫理的配慮と、専門家による厳格なデータ精査を行っている。 |
| どうやって有効だと検証した？ | 主要なオープンソースおよびクローズドモデルを評価。Arena Image Edit Leaderboardとの相関を分析し、既存ベンチマークと比較して最も人間の好みと一致するランキングを生成できることを示した。 |
| 議論はある？ | 実用的なデプロイシナリオでのオープンソースモデルの課題や、複雑な推論タスクにおけるプロンプトエンジニアリングの重要性が示された。一方で、さらなるドメインの拡張や評価手法の細分化が今後の課題。 |
