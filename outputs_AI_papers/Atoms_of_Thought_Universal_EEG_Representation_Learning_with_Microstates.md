# Atoms of Thought: Universal EEG Representation Learning with Microstates

| 項目 | 内容 |
|---|---|
| どんなもの？ | 脳活動の微細で安定したパターンである「マイクロステート」をEEG（脳波）信号のユニバーサルなトークンとして利用する、新しい表現学習手法です。大規模な睡眠データセットで学習したトークナイザーを、睡眠段階推定、感情認識、運動イメージ分類といった異なるタスクに汎用的に適用します。 |
| 先行研究と比べてどこがすごい？ | 従来の時系列・周波数ドメインの表現と異なり、ノイズやタスク固有のアーティファクトに強く、かつ生物学的な神経メカニズムに根ざした表現を実現しました。データ不足の環境下でも高い汎化性能を発揮し、スケーラビリティと解釈性に優れています。 |
| 技術や手法のキモはどこ？ | Human Sleep Project（2万件以上の被験者データ）を用いて、6つの主要チャンネルから得られるEEG信号をストリーミングK-meansでクラスタリングし、共通の「マイクロステート・トークナイザー」を構築した点です。これにより、離散的なマイクロステート列を深層学習モデルに入力可能にしました。 |
| どうやって有効だと検証した？ | 睡眠段階推定、感情認識、運動イメージ分類の3つの異なるタスクにおいて、CNN+LSTM、Sleep Transformer、Sleep Net Zero等の複数のモデル構造で評価を実施。従来の時系列・周波数解析手法を上回る分類精度とCohen's Kappaを達成しました。 |
| 議論はある？ | 現在は6チャンネルのデータに限定されている点、また訓練データが睡眠データに偏っている点が挙げられます。今後は、より多チャンネルなデータでの再構成や、さらに広範なタスクへの適用・拡張が課題です。 |
