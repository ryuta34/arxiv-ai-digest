# Agentic Societies Need a Social Harness

| 項目 | 内容 |
|---|---|
| どんなもの？ | 自律的なAIエージェントが協力する「エージェント社会」において、信頼境界を越えた連携の失敗や攻撃を防ぐための「ソーシャルハーネス（Social Harness）」という階層型アーキテクチャを提案する論文。 |
| 先行研究と比べてどこがすごい？ | 既存のマルチエージェントシステム研究が主に単一の目的を持つスワームや効率のみを重視していたのに対し、本研究は目的が部分的にしか合致しない独立したエージェント間での「社会的な通信失敗」や「悪意ある操作」に焦点を当てた点。 |
| 技術や手法のキモはどこ？ | IDの検証（L1）、信頼性の高い通信（L2）、エージェント自身を守る「パーソナルファイアウォール」（L3）、合意された規範（L4）、事後調査や制裁を行う社会的機関（L5）の5層からなる階層型防御構造。 |
| どうやって有効だと検証した？ | 大学の会議スケジューリングというタスクを用い、正直なエージェント同士の連携失敗（RQ1）と、故障・悪意あるエージェントによる攪乱（RQ2）をシミュレーション実験し、成功率とメッセージ量を分析した。 |
| 議論はある？ | ガードレール（L3）のレイテンシ増加、大規模社会への対応における協調とスループットのトレードオフ、規範が未定義な場合の対応などが今後の課題として挙げられている。 |
