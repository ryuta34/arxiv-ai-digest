# Universal YOCO for Efficient Depth Scaling

| 項目 | 内容 |
|---|---|
| どんなもの？ | 大規模言語モデルの推論時に、計算量を動的に増やすための再帰的計算（recursive computation）を効率的に統合したアーキテクチャ「Universal YOCO (YOCO-U)」です。既存のYOCOアーキテクチャをベースに、モデルの一部を再帰的に反復させることで、モデルパラメータを増やさずに表現力を向上させます。 |
| 先行研究と比べてどこがすごい？ | 全層を再帰させるUniversal Transformerと異なり、効率的なアテンションを用いた浅い層のみを再帰させることで、計算オーバーヘッドとメモリ消費を大幅に抑制しました。これにより、推論時の計算コストを抑えつつ、長文脈対応と高い推論性能を両立しています。 |
| 技術や手法のキモはどこ？ | セルフデコーダとクロスデコーダを分離し、セルフデコーダのみを反復させる設計です。セルフデコーダは効率的なアテンション（スライディングウィンドウ等）を使用するため、KVキャッシュが反復回数に応じて肥大化せず、一度生成されたグローバルなKVキャッシュをクロスデコーダが共有・再利用できる点にあります。 |
| どうやって有効だと検証した？ | 300Bトークンでの事前学習を行い、言語モデルタスクおよび11の数学ベンチマークで性能を評価しました。また、推論効率の観点から、スループット（トークン/秒）およびKVキャッシュメモリ使用量を、標準的なTransformerや既存の再帰的モデル（RINS等）と比較検証しました。 |
| 議論はある？ | 再帰的な深さが増すにつれて徐々に性能向上の度合いが鈍化するという「限界効用逓減」が示唆されています。また、本手法は推論時の計算能力拡張に特化しており、学習効率とは独立した手法であると位置づけています。 |
