# WorldCrafter: Consistent Video World Model with Implicit 3D-aware Memory

| 項目 | 内容 |
|---|---|
| どんなもの？ | 長時間のビデオ生成において、一貫した視覚体験と正確なカメラ制御を実現するビデオ世界モデル。カメラからクエリ可能な暗黙的な3D認識メモリを導入し、過去の観測を圧縮・再利用することで、長時間の探索においても安定したシーン再現を可能にする。 |
| 先行研究と比べてどこがすごい？ | 明示的な深度推定や複雑な幾何学計算を行わずに、学習可能なメモリエンコーダによって歴史的な観測を固定トークン予算内に圧縮・統合する点。これにより、従来手法と比較してメモリ処理のオーバーヘッドを21.7倍削減しつつ、視覚的再訪問の一貫性を大幅に向上させた。 |
| 技術や手法のキモはどこ？ | カメラの動きに合わせて過去のフレームから最適な情報を選択・統合する「max-coverage歴史検索」と、生成される将来のカメラ軌道に基づいて動的にメモリを抽出する「ポーズ誘導型読み出し（pose-guided readout）」の組み合わせ。 |
| どうやって有効だと検証した？ | 145のシーンと計725のカメラ軌道を含む独自ベンチマークを用い、長期間の再訪問一貫性（MEt3R, LPIPS等）、カメラ制御精度、VBenchによる映像品質を評価。他手法と比較し、全指標で優れた性能とリアルタイム性を達成した。 |
| 議論はある？ | 極めて複雑または過度に長い軌道では一貫性が低下する場合がある。また、現在のモデルでは各チャンクごとに歴史の再符号化を行っており、計算コストの増大が課題となっているため、将来的には新たなチャンクを段階的に追加するストリーミング更新メモリが必要である。 |
