# An Agency-Transferring Model-Free Policy Enhancement Technique

| 項目 | 内容 |
|---|---|
| どんなもの？ | 既存の（最適ではないが機能する）ベースライン方策を強化学習プロセスに組み込み、学習を効率化しつつ、最終的にベースラインから独立した高性能な方策を獲得する手法。学習初期はベースラインを強く活用し、段階的に学習方策へ権限を移行させる「エージェント転移」メカニズムを導入している。 |
| 先行研究と比べてどこがすごい？ | Residual RL（残差強化学習）がデプロイ時にもベースラインを必要とするのに対し、本手法は最終的にベースラインを完全に排除し、単独で動作するニューラルネットワークのみを生成する点。また、学習の初期・中間段階においても一貫して高い目標到達率を維持することを理論的に裏付けている。 |
| 技術や手法のキモはどこ？ | 批評家（Critic）の価値改善と確率的な緩和（アニーリング）を論理和（OR）で組み合わせた arbitration（調停）モジュール。これにより、現在の学習進度に基づいてベースラインと学習方策のアクションを自動的に切り替えるスケジュール制御を実現している点。 |
| どうやって有効だと検証した？ | 「汚染区域を含むAUV航行」と「宝探しロボット」という、ベースラインが明示的かつタスクに成功するが最適ではない2つの環境で実験。TD3およびSACをバックボーンとして使用し、目標到達率、タスク達成度、安全性指標を比較して、従来手法を上回る安定性と効率性を実証した。 |
| 議論はある？ | 目標到達に関する理論保証は有限エピソード期間における解釈的なものであり、実用上は環境の観測ホライズンに依存する。また、強化学習のバックボーンが学習に失敗した場合、ベースラインに依存したままで終わる可能性や、スケジュールのハイパーパラメータ設計が性能に与える影響が議論されている。 |
