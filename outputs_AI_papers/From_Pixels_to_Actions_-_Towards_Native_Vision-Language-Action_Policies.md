# From Pixels to Actions - Towards Native Vision-Language-Action Policies

| 項目 | 内容 |
|---|---|
| どんなもの？ | 視覚エンコーダーを排除し、画素から直接学習を行う「NEO-VLA」という新しいVision-Language-Action（VLA）フレームワーク。視覚情報の計算過程をバックボーンの各層で共有し、行動専門モデルがそこから柔軟に情報を抽出できるように設計されている。 |
| 先行研究と比べてどこがすごい？ | 既存のVLAモデルと異なり、事前に訓練された視覚エンコーダーに依存しない「構造的にネイティブ」な設計である点。また、行動予測のために最終的な視覚出力だけでなく、バックボーン内の計算途中の表現（中間層）を直接活用することで、より高精度で頑健な制御を実現した。 |
| 技術や手法のキモはどこ？ | 視覚エンコーダーを廃し、軽量なパッチ埋め込み層で画素をバックボーンのトークン空間に投影する設計。行動専門モデルがバックボーン内の任意の層からキャッシュされたKey-Valueを読み取り、フローマッチングを用いて連続的な行動を予測するアーキテクチャ。 |
| どうやって有効だと検証した？ | LIBERO、LIBERO-plus、RoboTwin 2.0、および実機ロボットを用いたタスク評価を実施。frozen（固定）バックボーンとフルファインチューニングの両設定で既存手法を上回る成功率を示し、視覚・幾何学的情報の抽出深さが性能に与える影響を解析した。 |
| 議論はある？ | 実装上の工夫により視覚や言語の変動には強い一方、空間的な構成変化や複雑な行動目標の変更に対してはまだ課題が残る。今後は、さらなる空間推論能力の向上と柔軟な適応が求められる。 |
