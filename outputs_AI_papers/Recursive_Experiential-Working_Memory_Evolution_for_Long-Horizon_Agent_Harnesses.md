# Recursive Experiential-Working Memory Evolution for Long-Horizon Agent Harnesses

| 項目 | 内容 |
|---|---|
| どんなもの？ | 長期的なタスクにおいて、外部化されたメモリ制御レイヤーを再帰的に進化させることで、LLMエージェントのパフォーマンスを向上させる手法「Recuris」を提案する論文。モデルの重み自体は固定したまま、メモリ管理メカニズムを最適化する。 |
| 先行研究と比べてどこがすごい？ | 従来手法が個別のタスクや最終結果のみから学習するのに対し、本手法は実行過程を「構造化されたトレース」として記録し、失敗を特定のメモリコンポーネント（WM、EM、方針等）に局所化して修正する。これにより、モデルの修正なしに、タスク成功率を大幅に改善（GPT-5.6で最大+17.8ポイント等）した。 |
| 技術や手法のキモはどこ？ | 作業メモリ（WM）と経験メモリ（EM）を密結合し、実行イベントごとに状態に基づいたスキル呼び出しを行う点。また、失敗の原因を構造化データからMeta-Agentが診断し、バリデーションゲートを経て局所的にメモリをパッチする「再帰的なメモリ進化ループ」を構築した点。 |
| どうやって有効だと検証した？ | 4つの長期ベンチマーク（𝜏²-Bench, SkillFlow, Terminal-Bench 2.1等）において、3Bからフロンティアモデルまで計10モデルを用いて評価。ベースライン（エージェント単体）に対し、多くのモデル・ベンチマークペアで一貫した成功率の向上を確認した。 |
| 議論はある？ | メモリの肥大化に対するプルーニング（剪定）の必要性や、複雑なタスクにおける「検証（Checker）」の設計がドメイン依存である点。また、学習の安定性と、進化させるメモリのコンポーネント数が過剰にならないような制限が挙げられている。 |
| 次に読むべき論文は？ | [Reflexion (Shinn et al., 2023)](https://arxiv.org/abs/2303.11366) や [Voyager (Wang et al., 2024)](https://arxiv.org/abs/2305.16291)、および本論文で言及されている[StructAgent (Wu et al., 2026)](https://arxiv.org/abs/2606.06079) が関連している。 |
