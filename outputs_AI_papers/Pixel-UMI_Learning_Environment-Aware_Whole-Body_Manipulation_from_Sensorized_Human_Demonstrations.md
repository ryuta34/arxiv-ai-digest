# Pixel-UMI: Learning Environment-Aware Whole-Body Manipulation from Sensorized Human Demonstrations

| 項目 | 内容 |
|---|---|
| どんなもの？ | センサー付きの人間のデモンストレーションから、モバイルマニピュレーション（移動操作）を学習するためのパイプライン「Pixel-UMI」です。環境を考慮したリターゲティングと、視覚情報のミスマッチを軽減する手法により、複雑な全身操作をロボットに習得させます。 |
| 先行研究と比べてどこがすごい？ | 人とロボットの身体構造の違いによる視覚的ミスマッチを、リターゲティングの誤差に基づいて学習時に動的にマスクすることで緩和しました。また、環境認識データを利用して、制約のある空間でも衝突を回避した高度な全身制御を実現しています。 |
| 技術や手法のキモはどこ？ | 環境認識に基づくオフラインリターゲティング「EAR」、リターゲティング誤差を用いて信頼度の低い視覚入力を抑制する「REAM」、およびタスク成功率を向上させるための「DAgger」によるオンポリシー修正です。 |
| どうやって有効だと検証した？ | 5つのモバイルマニピュレーションタスク（マウスの配置、テニス缶の梱包、ドリンクの取り出し、箱の折りたたみ、ジャケット掛け）で検証し、平均87.0%のタスク進行率を達成しました。特に接触を伴う複雑なタスクでの有効性を示しました。 |
| 議論はある？ | 現在の手法は接触を伴う相互作用の力を完全には把握できない点や、単一の深度カメラによるシーン構築に依存しており、隠れた表面や移動物体への対応に限界があります。より高度な接触情報の明示的な抽出が今後の課題です。 |
