# Context-Aware Interleaved Batching for WhisperX

| 項目 | 内容 |
|---|---|
| どんなもの？ | 長尺音声の文字起こしにおいて、WhisperXの並列処理による高速性と、標準Whisperの文脈維持能力を両立させる「Context-Aware Interleaved Batching」という手法を提案した研究です。VADで分割された音声チャンクを並列処理しつつ、FIFOバッファを用いて先行するチャンクのテキスト情報を後続へ伝搬させることで、文脈の欠落を解消します。 |
| 先行研究と比べてどこがすごい？ | 従来のWhisperXは高速ですが、音声が独立して処理されるため文脈が途切れ、専門用語や固有表現の精度が低下する欠点がありました。本手法は、推論速度を維持したまま、かつハルシネーション（幻覚）を引き起こしやすい内部タイムスタンプに頼らず、高い精度で継続的な文脈情報を伝搬できる点に優位性があります。 |
| 技術や手法のキモはどこ？ | VADで分割したシーケンスをラウンドロビン方式で並列ストリームに分散させ、各ストリーム内で前のチャンクの出力テキストを次のチャンクへの条件付き入力（プレフィックス）として再利用する点です。また、ストリーム開始時の文脈欠落（コールドスタート問題）を解決するため、最終バッチの結果を用いた再転写プロセスを導入しています。 |
| どうやって有効だと検証した？ | 財務収支報告の「Earnings-21」データセットおよび新規作成した医療講義データセットを用い、WER（単語誤り率）、Proper Noun Score（固有表現精度）、F1（句読点精度）などで比較評価しました。その結果、標準WhisperXと比較してWERを改善しつつ、約8.4倍の高速推論を実現しました。 |
| 議論はある？ | VADで分割された全チャンク数がバッチサイズ以下の場合、並列処理による文脈伝搬の効果が限定的になる点があります。また、句読点の精度に関しては、タイムスタンプに特化したモデル構造を持つ標準のWhisperには及ばない場合があることを認めています。 |
