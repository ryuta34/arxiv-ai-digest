# From Seeing to Acting: Smart Glasses as First-Person Intelligence Platforms

| 項目 | 内容 |
|---|---|
| どんなもの？ | スマートグラスを単なる周辺機器ではなく、人間の視点に基づいた「一人称インテリジェンス・プラットフォーム」として体系的に定義・調査した初の網羅的なサーベイ論文。ハードウェアの制約、データフロー、能力フレームワーク（L0-L5）、応用シーン、およびデプロイメント・評価のガイドラインを包括的に提示している。 |
| 先行研究と比べてどこがすごい？ | 個別の技術（ビジョン、AIモデル、HCIなど）に分断されていた研究領域を、スマートグラス特有の「閉ループシステム（感覚→推論→状態維持→行動・フィードバック）」という視点で統合した点。また、性能を単一の指標で測るのではなく、ハードウェア・環境・タスクのリスク等に依存する「条件付き能力（claim-conditioned capability）」として定義した点。 |
| 技術や手法のキモはどこ？ | スマートグラスの能力を8つのハードウェア軸に集約し、さらにL0（記録・中継）からL5（具現化された結合）までの5段階のレベル（L0-L5）で体系化したフレームワーク。また、研究や評価を再現可能にするための設計・デプロイメントの9つの次元（ハードウェア、ランタイム、推論スタックなど）を定義し、実用的な評価基準を提供している点。 |
| どうやって有効だと検証した？ | 9つの応用シーン（日常生活支援、アクセシビリティ、産業ワークフロー、医療、教育、移動・安全、ソーシャル等）ごとに、既存のデータセット、ベンチマーク、研究プロトタイプ、市販製品を分類し、体系的にマッピングすることでフレームワークの網羅性と実用性を検証した。 |
| 議論はある？ | センサーの数やディスプレイの複雑さが能力に直結するわけではなく、各デバイスが限られたリソース（重さ、熱、電力、プライバシー等）をどう配分するかのトレードオフが重要であると論じている。今後は、単なる認識精度だけでなく、継続的な運用環境下での安全性、信頼性、プライバシー保護、責任の所在といったシステム全体の頑健性が不可欠。 |
