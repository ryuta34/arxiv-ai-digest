# WorldCup Arena: Prospective, Leakage-Free Evaluation of Frontier LLMs on a Live Tournament

| 項目 | 内容 |
|---|---|
| どんなもの？ | 2026年FIFAワールドカップの全104試合を対象に、6つのフロンティアLLMが試合開始前に予測を行うことで、データ汚染のない（リークフリーな）予測性能を評価する新しいベンチマーク。将来のイベントを対象とすることで、検索や推論を用いた予測能力を客観的に測定している。 |
| 先行研究と比べてどこがすごい？ | 従来のベンチマーク（Autocast等）は過去の事象に基づいた遡及的評価であり、学習データへの混入（リーク）が問題となっていた。本作は「試合開始前」に予測を完結させる設計により、構造的にリークを排除した真の将来予測ベンチマークを実現した点。 |
| 技術や手法のキモはどこ？ | 試合前に毎日更新される「チーム・スタッツ等の詳細なドキュメント（ドシエ）」と「ライブウェブ検索」をLLMに提供し、全104試合に対して一貫した予測フォーマットを課す点。また、スナップショット、キックオフ時間、テンプレートという3つの技術的ロックでリークを防いでいる。 |
| どうやって有効だと検証した？ | 6つのフロンティアLLMを用いて39日間のトーナメント期間中、合計4,494件の予測データを取得。ブックメーカーのオッズを競合基準とし、モデル間の一致度、予測精度の推移、スコアリング手法によるランク変動などを多角的に分析・比較した。 |
| 議論はある？ | LLMの予測はブックメーカーのオッズを上回ることはできず、モデル間での行動パターン（引き分けや得点を過少評価する傾向など）が驚くほど類似している。単一のドメインにおける事象に限定されるため、汎用的な予測能力の評価としては規模や多様性が課題となる。 |
