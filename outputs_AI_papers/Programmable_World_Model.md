# Programmable World Model

| 項目 | 内容 |
|---|---|
| どんなもの？ | 視覚的な動画生成と、エンジンによる明示的な世界状態（エンティティの属性やルール）の管理を分離した、プログラム可能なビデオ世界モデル。ユーザーの指示に基づき、軽量なエンジンが世界状態を更新し、それを条件として高品質なビデオを生成することで、ゲームのような永続的かつインタラクティブな体験を実現する。 |
| 先行研究と比べてどこがすごい？ | 従来のモデルが暗黙的な状態管理に依存していたのに対し、本手法は明示的な「エンジンによる状態管理」を導入。これにより、オフスクリーンを含むエンティティの追跡や、ユーザー定義のルールに基づく永続的な世界状態の維持が可能となり、長期的な一貫性が大幅に向上している。 |
| 技術や手法のキモはどこ？ | エンティティを「状態が付与された3D指向性バウンディングボックス（OBB）」として定義し、それらを deterministically（決定論的）に画素整列された時空間制御信号にコンパイルしてビデオモデルの入力とする点。これにより、エンジンによるルール処理と生成モデルによる視覚表現を効率的に接続している。 |
| どうやって有効だと検証した？ | CombatStateBenchという新規ベンチマークを構築し、既存のインタラクティブビデオ世界モデル（LingBot-World-V2等）と比較評価。カウント精度（生存キャラクター数）や状態精度（死亡イベントの視覚的再現）などの指標で、従来手法を圧倒する高い精度を達成した。 |
| 議論はある？ | 現在の手法は、高レベルな状態遷移から構造的表現を生成するプロセスに依存している。また、完全に詳細なシミュレーションと比較すると生成モデル側の限界があるが、明示的な状態管理によって永続性とインタラクティブ性を維持しつつ、視覚的リアリズムとの両立を図る枠組みを提示している。 |
