# PhysiCalWorld: In-Context Physics Calibration for World Models

| 項目 | 内容 |
|---|---|
| どんなもの？ | 未知の環境で得られたわずかなインタラクション（行動・観測）を「物理記述トークン」に圧縮し、ワールドモデルをその環境の物理特性に適応させるゼロショット手法。事前に物理式や教師データを用いることなく、動画予測の目的関数のみで学習可能な物理カリブレーションフレームワーク。 |
| 先行研究と比べてどこがすごい？ | 解析的な物理モデルの構築や高コストなファインチューニングを不要とし、軽量なトークン化により推論時の計算コストをほぼ増やさずに、複雑で未知の環境へのゼロショット適応を実現した点。また、物理パラメータを明示的に指定せず、動画データから自己教師あり学習で物理特性を抽出できる。 |
| 技術や手法のキモはどこ？ |  exploratoryなインタラクションクリップを軽量なTransformerベースのコンテキストエンコーダで単一の「物理記述トークン（zphy）」に圧縮し、それをワールドモデルの入力として結合・条件付けする点。これにより、長い過去履歴を保持するコストなしで、物理特性を反映した精度の高い未来予測が可能となる。 |
| どうやって有効だと検証した？ | Push-T、Reacher、BeerPong、FetchSlideの4つのシミュレーション環境において、DINO-WMおよびLeWMをベースに評価。単一および複合的な物理変動がある環境下で、ベースライン手法（Long HistoryやContext Prefix等）と比較し、Rollout精度（PSNR、IoU等）やタスク成功率（SR）が向上することを示した。 |
| 議論はある？ | トレーニング時に物理特性ごとにデータをグループ化する必要がある点や、インタラクションプロンプトの品質に精度が依存する点。また、環境内での物理特性が不変（定常的）であることを前提としているため、動的な変動環境への対応が今後の課題。 |
