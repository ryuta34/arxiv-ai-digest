# VoxProg: 3D Spatial Reasoning through Voxel Programming

| 項目 | 内容 |
|---|---|
| どんなもの？ | 言語モデルを用いて、3Dシーン上の物体配置タスクを解決するための新しいフレームワーク「VoxProg」です。シーンのメッシュ表面をボクセル化し、プログラムを通じてタスクに適した幾何学的参照を構築することで、高精度な6自由度の物体配置を実現します。 |
| 先行研究と比べてどこがすごい？ | 事前に定義された空間関係やスパースなキーポイントに依存せず、実行コードによる動的な幾何学的参照の構築を可能にしました。これにより、複雑な形状や機能的な配置が求められるタスクにおいて、既存のベースライン（GenManipやDirect Mesh等）を大きく上回る性能を達成しています。 |
| 技術や手法のキモはどこ？ | 「ボクセルプログラミング」という手法を用い、タスクに応じた解像度でシーン表面を局所的なボクセルグリッドに変換し、プログラム操作（スライス、隣接関係抽出等）によって直接的に幾何学的証拠を抽出・検証する点です。 |
| どうやって有効だと検証した？ | 71種類の言語指示に基づく配置タスクからなる新ベンチマーク「VoxProg-Bench」を構築し、パーセプチュアルな整合性（IA Rank Score）と物理的な妥当性（支持や非貫通チェック）の両面から評価を行いました。また、RoboCasaやOpen6DOR v2を用いた外部評価も実施しています。 |
| 議論はある？ | 2Dの視覚情報のみでは、遮蔽物によって3D空間上の微細な浮きや貫通を見抜けない場合があること（視覚的曖昧さ）を指摘しています。プログラム生成における反復的な修正プロセスが必要であり、完全に自動化された操作実行への拡張が将来の課題です。 |
