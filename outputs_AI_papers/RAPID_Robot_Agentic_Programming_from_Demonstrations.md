# RAPID: Robot Agentic Programming from Demonstrations

| 項目 | 内容 |
|---|---|
| どんなもの？ | 1つの視覚的な人間によるデモンストレーションから、ロボットの動作プログラムを自動生成・検証・精緻化する「RAPID」というフレームワーク。事前の報酬関数や環境設定なしで、複雑な非把持操作タスクを含む再利用可能なプログラムを構築できる。 |
| 先行研究と比べてどこがすごい？ | 従来手法が前提としていた「事前定義されたタスク報酬」「手動設計されたプリミティブ」「リセット可能な検証環境」を必要とせず、デモンストレーションからこれらを自動的に導出する点。プログラムの構造をオブジェクト中心の「関係的」な表現にすることで、環境変化に対する高い汎化性能を実現した。 |
| 技術や手法のキモはどこ？ | 操作を「 trajectory-optimization（軌道最適化）」として表現し、それを「関係的制約」で構成するプログラム表現。デモンストレーションに基づくインタラクティブなシミュレーション環境の自動構築と、検証・修正を繰り返すエージェント的なコーディングループの活用。 |
| どうやって有効だと検証した？ | 8つの接触を伴う複雑な非把持操作タスクを対象に、シミュレーションと実機（Franka arm）で実験を実施。既存のコード生成手法（CaP等）と比較し、オブジェクトや環境の多様性がある状況下で高い成功率を達成したことを示した。また、LIBERO-Proベンチマークでも評価した。 |
| 議論はある？ | 現在は剛体操作が中心であり、変形物体の操作には課題がある。また、プログラム構築には数十分の計算時間を要するため、リアルタイムな環境即応性には改善の余地がある。 |
