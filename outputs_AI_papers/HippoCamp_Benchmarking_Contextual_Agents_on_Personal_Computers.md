# HippoCamp: Benchmarking Contextual Agents on Personal Computers

| 項目 | 内容 |
|---|---|
| どんなもの？ | 個人のコンピュータ環境におけるマルチモーダルファイル管理タスクを評価するための新しいベンチマーク「HippoCamp」を提案。実ユーザーから得られたデータに基づき、ファイル検索、内容理解、および多段階の推論能力を測定する環境を実現している。 |
| 先行研究と比べてどこがすごい？ | Webブラウジングや特定のツール使用に特化した既存ベンチマークとは異なり、長期にわたる個人の複雑なファイル構造、多様な形式（文書、画像、音声、動画等）、およびユーザー特有の行動履歴を統合的に扱う点。 |
| 技術や手法のキモはどこ？ | 現実のユーザーから抽出した環境を構築し、581のQAペアと46.1Kの構造化された推論トラジェクトリを付与した点。また、検索、知覚、推論というエージェントの基本能力を段階的に診断可能な階層的アノテーションスキームを採用している。 |
| どうやって有効だと検証した？ | RAG手法、検索エージェント、自律型エージェント（ChatGPT Agent Mode等）など、最新のモデルを比較検証。プロファイリングと事実保持のタスクを通じ、最高性能のモデルでも正解率が低く、特に長期間の文脈理解やマルチモーダルな推論に課題があることを証明した。 |
| 議論はある？ | 現在のエージェントは個々のファイルを探す能力はあるが、それらを統合してユーザーの長期的な習慣や嗜好を推論する能力が不足している。また、計算コストが高く動作が不安定であるため、実用化には効率性と推論の堅牢性が不可欠である。 |
