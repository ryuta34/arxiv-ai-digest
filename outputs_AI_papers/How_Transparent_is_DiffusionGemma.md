# How Transparent is DiffusionGemma?

| 項目 | 内容 |
|---|---|
| どんなもの？ | テキスト拡散モデル「DiffusionGemma」の透明性と推論プロセスを分析した研究。モデルが中間状態で行う非自己回帰的な推論が、従来の自己回帰型モデルと比較してどの程度解釈可能か、また監視可能かを調査している。 |
| 先行研究と比べてどこがすごい？ | 拡散モデル特有の非時系列的な推論（後方修正や同時並行的な候補生成）を可視化し、モデルの推論過程が必ずしも左から右への線形ではないことを実証した点。また、拡散モデルでも従来の自己回帰モデルと同等の監視可能性（monitorability）を維持できることを示した。 |
| 技術や手法のキモはどこ？ | 推論ステップ間に存在する「情報ボトルネック」を解釈可能なトークンとしてマッピングする手法と、Logit Lensを用いた中間状態の分析。さらに、モデルが「最終トークンの推測」として中間状態を利用していることを定量的に証明した。 |
| どうやって有効だと検証した？ | 複数の推論ベンチマークにおいてモデルの性能を測定し、独自の可視化ダッシュボード（Summary View, Line Graph, Sampling Table）を用いて、非時系列的な推論パターン（早期の長さ予測、遡及的自己修正、トークン/シーケンスの塗りつぶし現象）を解析した。 |
| 議論はある？ | 現在の監視可能性は拡散モデルの学習パラダイムに依存している可能性があり、より大規模なキャンバスサイズを持つモデルでは、推論がより不透明になるリスクがある。また、中間状態の解釈は、意図的な不正やデセプションを誤判定するリスクを排除できない。 |
