# Bidirectional Cross-Modal Prompting for Event-Frame Asymmetric Stereo

| 項目 | 内容 |
|---|---|
| どんなもの？ | イベントカメラとフレームカメラを組み合わせた非対称ステレオマッチングのための、双方向クロスモーダル・プロンプティング手法「Bi-CMPStereo」。両ドメインの補完的な情報を活用し、ロバストな深度推定を実現する。 |
| 先行研究と比べてどこがすごい？ | 従来の手法がドメイン間の整合性を取る過程でドメイン特有の重要な特徴を損なっていたのに対し、本手法はターゲットドメインの正準空間へ両者を投影することで、各ドメインの特徴を保持しつつ高精度なアライメントを達成した。 |
| 技術や手法のキモはどこ？ | ドメイン特有のエンコーダーを学習させる「ステレオ正準化制約（SCC）」と、ソースドメインをターゲットドメインの分布に近づける「クロスドメイン埋め込みアダプター（CDEA）」、およびcontextのショートカット学習を防ぐ「階層的視覚変換（HVT）」。 |
| どうやって有効だと検証した？ | DSECデータセットを用いた定量的評価に加え、MVSECおよびM3EDデータセットを用いたクロスデータセット汎化性能の評価を行い、既存の非対称および対称ステレオ手法を大幅に上回る精度を実証した。 |
| 議論はある？ | 複数のネットワークを用いたパイプライン構成のため、単一のモデルで完結する手法と比較した際の推論時の計算リソースやモデルの複雑さが課題となり得る。 |
