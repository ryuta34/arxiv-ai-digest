# Repurposing 3D Generative Model for Autoregressive Layout Generation

| 項目 | 内容 |
|---|---|
| どんなもの？ | 言語指示に基づき、3D空間で直接オブジェクトを順次配置して3Dシーンレイアウトを生成する自己回帰型フレームワーク。従来のテキストベースの手法が抱えていた物理的な不整合（衝突や浮きなど）を解消し、高品質な3Dシーン生成を実現する。 |
| 先行研究と比べてどこがすごい？ | 従来の言語ベースの手法が持つ物理的制約の欠如を克服し、3D空間ネイティブで生成を行うため、物理的妥当性が19%向上した。また、自己回帰プロセスにより、従来の手法と比較して計算コストを約65%削減している。 |
| 技術や手法のキモはどこ？ | 3D生成モデルの幾何学的先験知識（Prior）を転用した「適応型3D拡散モデル」と、シーンレベルとオブジェクトレベルの二重の教師信号で学習する「自己ロールアウト蒸留（Dual-Guidance Self-Rollout）」による露出バイアスの抑制。 |
| どうやって有効だと検証した？ | LayoutVLMのベンチマークを用い、衝突率（CF）、境界違反率（IB）、幾何学的一貫性、計算速度を定量的および定性的に比較。また、43名の被験者によるユーザー調査を行い、物理的妥当性と全体的な品質の優位性を実証した。 |
| 議論はある？ | 現在は64³という解像度の3Dグリッドに制約されており、小物の配置で不整合が生じる可能性がある。また、複雑な空間構成に関する高品質なデータセットの不足が、生成の意味的一貫性を制限している。 |
