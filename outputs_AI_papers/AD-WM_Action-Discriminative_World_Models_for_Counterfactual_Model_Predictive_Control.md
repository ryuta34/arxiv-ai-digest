# AD-WM: Action-Discriminative World Models for Counterfactual Model Predictive Control

| 項目 | 内容 |
|---|---|
| どんなもの？ | 従来の潜在世界モデルが抱える「事実予測誤差の最小化と、計画（プランニング）時の行動識別の不一致」を解消する、アクション識別型世界モデル「AD-WM」。モデル予測制御（MPC）において、行動に依存する微小な変化を正確に保持し、対事実（カウンターファクトゥアル）的な比較を可能にすることで、ロボット制御の精度を大幅に向上させる手法。 |
| 先行研究と比べてどこがすごい？ | 従来のJEPAベースのモデルは視覚的予測には優れるが、行動の影響を正確に捉えられず、計画時の意思決定に寄与しにくいという欠点があった。AD-WMは事実予測だけでなく行動回復を学習目標に加えることで、物体操作などのタスクにおいて、困難な初期状態からの成功率を大幅に改善（例：Cube環境の難度P04で3.7%から52.0%へ向上）した。 |
| 技術や手法のキモはどこ？ | 潜在空間における残差予測に、逆動力学（Inverse Dynamics）と条件付き相互情報量（MI）に基づく正規化された行動回復学習を組み合わせた点。これにより、予測された潜在遷移に対して行動情報を不可逆的に埋め込み、MPCが候補となる複数の行動系列を評価する際、ゴールに向けた微細な動きの差異を判別可能にした。 |
| どうやって有効だと検証した？ | 5つのロボットシミュレーション環境（Cube, Reacher, TwoRoom, PushT, OGBench）でLeWM等の既存ベースラインと比較検証を行った。また、実機のFrankaロボットを用いたゼロショット転移実験を行い、ピック・アンド・プレースタスクで成功率を42.2%から71.1%に引き上げることで、その実用性と汎用性を証明した。 |
| 議論はある？ | 実験による診断（CADやエリートレグレット）はCube環境に限定されており、他の環境への適用性には検討の余地がある。また、学習時の補助損失関数の設定がロボット制御において重要だが、シミュレーションと実機でパラメータが異なる点や、現状では手動のサブゴール設定に依存している点が将来的な課題である。 |
| 次に読むべき論文は？ | [LeWorldModel](https://arxiv.org/abs/2606.26217)や[V-JEPA 2](https://arxiv.org/abs/2506.09985)（本研究の主要なベースラインおよび比較対象のため）。 |
