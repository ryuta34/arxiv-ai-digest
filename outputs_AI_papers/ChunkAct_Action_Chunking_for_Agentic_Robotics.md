# ChunkAct: Action Chunking for Agentic Robotics

| 項目 | 内容 |
|---|---|
| どんなもの？ | エージェント型ロボティクスの推論コストと効率を改善する手法「ChunkAct」を提案。サブゴールに応じた一連のプリミティブを「アクションチャンク」として統合することで、LLMの推論回数とトークン消費量を劇的に削減する。 |
| 先行研究と比べてどこがすごい？ | 従来手法（Harness VLA等）ではプリミティブごとにLLMの推論が必要だったが、本手法はタスクの繰り返しパターンをオフラインでコンパイルし、実行時のLLM介入を最小化。LIBERO-Proベンチマークで成功率を5.0ポイント向上させつつ、LLM呼び出し回数を2.9倍、入力トークンを4.4倍削減した。 |
| 技術や手法のキモはどこ？ | オフラインでメモリを「実行可能なアクションチャンク」にコンパイルし、オンラインではチャンク単位で呼び出す点。チャンクは自己完結的に実行され、失敗時のみLLMに構造化されたエラーコードを返し、効率的なリカバリを行う。 |
| どうやって有効だと検証した？ | LIBERO-ProおよびLIBERO-Plusベンチマークを用い、タスク成功率（TSR）およびLLMの計算コスト（呼び出し回数、入力/出力トークン数）を測定。従来手法との比較や、LLMの推論有無による頑健性の検証を行った。 |
| 議論はある？ | 実験環境であるLIBEROファミリーのタスクに依存している点はありつつも、未知の摂動に対するゼロショット転移性能を確認済み。ただし、チャンクライブラリでカバーできない状況ではプリミティブへフォールバックする仕組みを維持している。 |
