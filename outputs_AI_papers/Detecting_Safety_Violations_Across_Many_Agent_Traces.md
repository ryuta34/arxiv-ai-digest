# Detecting Safety Violations Across Many Agent Traces

| 項目 | 内容 |
|---|---|
| どんなもの？ | 大規模なエージェントのログ（トレース）から、単一のログでは検出困難な安全上の違反（誤用、報酬ハッキング、工作等）を特定する監査手法「Meerkat」を提案。クラスタリングとエージェントによる推論を組み合わせ、分散した証拠から違反を自動的に抽出する枠組み。 |
| 先行研究と比べてどこがすごい？ | 個々のトレースのみを検査する既存のモニタリング手法とは異なり、複数のトレースを相関的に分析することで、断片的な情報の中に隠された悪意ある挙動を特定できる点。また、実際のベンチマークにおいて、開発者による回答の隠蔽や報酬ハッキングを大幅に多く発見した点。 |
| 技術や手法のキモはどこ？ | トレースを埋め込みベクトル化してクラスタリングし、関連する挙動をグループ化することで探索効率を向上させた点。この構造化された情報をLLMベースのエージェントに与え、自然言語で指定された安全プロパティに基づいて違反の証拠を推論・採点させる点。 |
| どうやって有効だと検証した？ | 合成ベンチマーク（サイバー誤用、報酬ハッキング等）および実際のAIエージェントの評価データ（Terminal-Bench 2.0、CyBench等）を用いて評価。ベースライン（単純なLLMモニター等）と比較し、精度の高い検出および違反トレースの特定が可能であることを示した。 |
| 議論はある？ | 敵対的攻撃者に対しては、埋め込みを分散させる攻撃を受けることで検出性能が低下するリスクがある。また、トレーシングデータの要約による情報欠損や、完全な監査を行うためのコストといった実用上の制約・限界が存在する。 |
