# FrontierPhysics: Evaluating Agents for End-to-End Physics Research

| 項目 | 内容 |
|---|---|
| どんなもの？ | 物理学研究の全プロセス（文献調査から論文執筆まで）を自動実行できるAIエージェントを評価するための、専門家が設計した包括的なベンチマーク。理論、計算、実験物理学の9分野にわたる56のタスクで構成されている。 |
| 先行研究と比べてどこがすごい？ | 既存のベンチマークが単一のタスクや定型的な問題に偏っていたのに対し、本研究は著者自身の研究に基づく実践的な課題を用いることで、AIの科学的洞察力、推論の厳密さ、研究計画の立案能力を包括的に評価できる点。 |
| 技術や手法のキモはどこ？ | 決定論的な検証器（コードによる正誤判定）と、AIエージェントによる rubric（評価基準）に基づいた論文の質的評価の組み合わせ。また、単なる「正誤」ではなく「ブロック（必須要件）」と「ノンブロック（質的評価）」に分けた評価指標を採用している。 |
| どうやって有効だと検証した？ | 22のモデルと4つのエージェントハーネスを用い、計4,364回の試行を実施。各モデルの成功率を測定するとともに、物理学者の専門家による詳細な失敗モード分析を行い、現在のAIが抱える弱点（厳密な推論の不足や専門的な直感の欠如）を特定した。 |
| 議論はある？ | AIの失敗は物理知識の不足よりも、「循環的な自己検証」や「境界条件の考慮不足」といった論理的な厳密性の欠如に起因することが多い。また、タスク設計者の意図がエージェントに伝わりにくいという「指示追従」の限界も指摘されている。 |
