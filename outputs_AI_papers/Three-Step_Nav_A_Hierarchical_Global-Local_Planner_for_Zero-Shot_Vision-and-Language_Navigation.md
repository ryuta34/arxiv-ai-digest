# Three-Step Nav: A Hierarchical Global-Local Planner for Zero-Shot Vision-and-Language Navigation

| 項目 | 内容 |
|---|---|
| どんなもの？ | ゼロショットの視覚・言語ナビゲーション（VLN）において、MLLM（マルチモーダル大規模言語モデル）を活用した階層的なグローバル・ローカルプランナー「Three-Step Nav」を提案。環境内のナビゲーションを「先読み」「現在の行動」「振り返り」の3ステップで構成し、長距離のナビゲーションにおけるドリフトや迷いを解消する。 |
| 先行研究と比べてどこがすごい？ | 従来手法は現在の視覚情報と履歴のみに依存しがちで、長距離航行でドリフトが発生しやすかったが、本手法はグローバルな進捗確認と軌跡レベルの検証を導入することで、ゼロショット性能においてSOTAを達成。特にR2R-CEデータセットでナビゲーション誤差を15%、SPLを12%改善した。 |
| 技術や手法のキモはどこ？ | 命令を部分的なサブ指示に分解してグローバルな地図を作る「look forward」、サブ指示に基づきローカルな移動先を選択する「look now」、過去の軌跡を再検証して必要に応じてバックトラッキングや自己補正を行う「look backward」のループ構造。 |
| どうやって有効だと検証した？ | R2R-CEおよびRxR-CEの2つの標準ベンチマークを用い、他のゼロショット手法と比較。また、提案した各モジュール（先読み・振り返り）の寄与を検証するアブレーションスタディと、異なるMLLMエキスパート（GPT-5, GPT-4o, GPT-4v）間での性能比較を実施。 |
| 議論はある？ | 現在は固定のMLLMに依存しており計算コストがかかる点、およびシミュレーション環境での評価に留まっている点。実機転用にはセンサーノイズや障害物への対応が必要であり、フィードバックを通じた学習機能の実装が将来課題である。 |
| 次に読むべき論文は？ | [Open-Nav](https://arxiv.org/abs/2502.04692) や [SmartWay](https://arxiv.org/abs/2502.00000) などのゼロショット連続環境ナビゲーション研究が挙げられる。 |
