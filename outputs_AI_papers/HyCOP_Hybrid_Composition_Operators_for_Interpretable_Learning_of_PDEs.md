# HyCOP: Hybrid Composition Operators for Interpretable Learning of PDEs

| 項目 | 内容 |
|---|---|
| どんなもの？ | 偏微分方程式（PDE）の求解において、物理的なプロセスに基づいた複数のサブモジュールを、クエリに応じて動的に合成する学習型フレームワーク「HyCOP」を提案。単一のブラックボックスモデルを学習するのではなく、 advection（移流）や diffusion（拡散）などの物理的基礎演算子を学習可能なポリシーで柔軟に組み合わせて解を構築する。 |
| 先行研究と比べてどこがすごい？ | モノリシックなニューラル演算子（FNO等）とは異なり、各物理プロセスを個別に扱うため、分布外（OOD）データに対して頑健であり、プロセスレベルでの失敗診断やモジュール単位の交換・転移が可能。さらに、固定の演算子分割ではなくクエリ条件に応じた動的なプログラム生成を行うことで、オーダー単位の精度向上と計算効率の改善を実現した。 |
| 技術や手法のキモはどこ？ | PDEを基礎的なサブフローに分解し、それらを辞書（Dictionary）として定義。学習されたポリシーπθが、現在の状態と regime 特徴量（ペクレ数など）に応じて「どのモジュールを、どのくらいの時間（τ）適用するか」というプログラムを生成する点。また、微分不可能なレガシーソルバーも扱えるよう、Evolution Strategies（ES）を用いた最適化を採用している。 |
| どうやって有効だと検証した？ | ナビエ・ストークス方程式、浅水方程式、ADR方程式、倉本・シバシンスキー方程式など5つのベンチマークで評価。既存のニューラル演算子と比較して、OOD環境下でオーダー単位の誤差低減を達成し、訓練効率が25倍以上向上したことを確認した。また、境界条件の交換や欠損物理（反応項）の追加といったモジュール転移がゼロショットで可能であることを示した。 |
| 議論はある？ | 辞書の構築にはドメイン知識が必要であり、未知の物理現象を完全に自動発見できるわけではない。また、現在の実装では基礎ソルバーの計算コストに依存する。今後の課題として、全自動的なプリミティブの学習や、気候・気象モデリングのような大規模なFoundation Modelへの応用、記号探索を用いた自動的な分割スキーマの発見が挙げられている。 |
