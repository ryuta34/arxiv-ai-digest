# WorldSculpt: Generating Compositional Worlds from Grounded Videos

| 項目 | 内容 |
|---|---|
| どんなもの？ | 多数の物体が密集し、激しく遮蔽された複雑なシーンから、各物体を個別に編集可能なメッシュとして生成する手法「WorldSculpt」を提案。単一物体用の強力な3D生成モデルを、シーンレベルの学習なしでマルチビュー条件付けにより大規模シーンへ応用した。 |
| 先行研究と比べてどこがすごい？ | 従来のシーン生成モデル（Marble等）は単一の不連続な表現（ガウス分布など）しか出力できないが、本手法は各物体を独立したメッシュとして生成・配置できる。また、シーン全体を学習する必要がなく、個別の物体事前知識のみで、数百の物体が絡む高度に遮蔽されたシーンにも対応可能である。 |
| 技術や手法のキモはどこ？ | 物体ごとに「アンカー配置型の正規化されたカノニカルフレーム」を構築し、そこへマルチビューのDINOv3特徴量をリフティングして、順序不変な集約モジュールで融合する点。さらに、学習済みモデルの凍結部分を保持しつつ、ゼロ初期化された射影層とLoRAでマルチビュー情報を注入する設計を採用している。 |
| どうやって有効だと検証した？ | 提案の「UE-MeshyScene」ベンチマーク（6つのフォトリアルな環境、合計2,299の物体）に加え、Toys4kやHouseCat6Dを用いて検証。特に、遮蔽率の異なる条件下でのChamfer距離やF-scoreによる定量的評価を行い、既存手法と比較して遮蔽が強い環境ほど高い精度向上を実現した。 |
| 議論はある？ | カメラ姿勢やインスタンスマスク、粗い3D位置推定というアップストリームの推定に依存している点。現在は静的なシーンに限定されており、物体の移動や変形、また外観・質感の生成モデル化が今後の課題である。 |
