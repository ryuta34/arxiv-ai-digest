# R-DMesh: Video-Guided 3D Animation via Rectified Dynamic Mesh Flow

| 項目 | 内容 |
|---|---|
| どんなもの？ | 単眼ビデオの動きをガイドとして、静的な3Dメッシュを高品質な4Dメッシュアニメーションに変換するフレームワーク。ユーザーが提供するメッシュとビデオの開始ポーズの不一致（ポーズアライメントの欠如）という実用上の課題を解決した。 |
| 先行研究と比べてどこがすごい？ | 従来手法で問題となっていたポーズの不一致による歪みを解消し、スケルトン等に依存せず多様なオブジェクトを扱える。さらに、Rectified Flowを用いた生成により、計算効率を維持しつつ時間的に一貫した高精度なアニメーションを実現した点。 |
| 技術や手法のキモはどこ？ | 入力メッシュを「基底メッシュ」「ジャンプオフセット」「相対的な動きの軌跡」に分離するVAEの導入。特に、メッシュの幾何学的特徴に基づき3つのフローを協調させる「Triflow Attention」機構により、物理的な整合性と局所的な剛性を保つ工夫。 |
| どうやって有効だと検証した？ | 50万以上の動的メッシュを含む大規模データセット「Video-RDMesh」を構築し、既存の4D生成手法やアニメーション手法と比較。PSNRやVBenchメトリクス（SC/SM）、幾何学的誤差（Euclidean Distance）で高い精度と推論速度を実証。 |
| 議論はある？ | メッシュの自己交差（インターペネレーション）が発生する場合がある点や、学習データが少ない希少なオブジェクトに対する合成品質の低下が課題。今後はデータフィルタリングの改善や後処理最適化による強化を目指す。 |
