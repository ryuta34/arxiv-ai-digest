# Steerable Visual Representations

| 項目 | 内容 |
|---|---|
| どんなもの？ | 既存の学習済みVision Transformer (ViT) を自然言語で「操縦（Steer）」し、視覚特徴を特定のオブジェクトや概念に集中させる手法「SteerViT」。視覚エンコーダの内部層に軽量なクロスアテンションを挿入することで、表現品質を損なわずに柔軟な制御を可能にする。 |
| 先行研究と比べてどこがすごい？ | 従来のCLIPのような後期融合（Late Fusion）では視覚表現を直接制御できず、マルチモーダルLLMは計算コストが高い。SteerViTは凍結したViTの内部に少数のパラメータ（21M）を挿入するだけで、視覚表現の品質を維持しつつ、テキストによる強力な制御（Steerability）を実現した点が新規である。 |
| 技術や手法のキモはどこ？ | 凍結したViTブロック間に「ゲート付きクロスアテンション層（Gated Cross-Attention）」をインターリーブするEarly Fusionアプローチ。学習時は参照セグメンテーションを目的関数とし、推論時はゲート係数（$\alpha_\ell$）を調整することで、ViTの汎用性とテキスト制御のトレードオフを制御可能にした。 |
| どうやって有効だと検証した？ | 独自ベンチマーク「CORE」を用いたテキスト条件付き画像検索、MOSAICベンチマークによる注意領域の視覚化、およびPODSやMVTec ADなどのデータセットを用いた、下流タスク（分類、セグメンテーション、異常検知）での評価により、ゼロショット転移性能と表現品質を検証した。 |
| 議論はある？ | 言語プロンプトが抽象的すぎると表現の粒度が粗くなる点や、ベースとなるViTの性能に依存する点。また、異常検知において明らかに異常がないケースでは誤検知が生じる可能性があることや、さらなる言語理解の向上のための学習期間の最適化が将来の課題として挙げられている。 |
