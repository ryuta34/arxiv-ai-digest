# Latent Spatial Memory for Video World Models

| 項目 | 内容 |
|---|---|
| どんなもの？ | 3D空間の一貫性を保つビデオ生成のための、潜在空間ベースの永続的な3Dメモリシステム「Mirage」を提案する研究。従来のようにRGB点群をレンダリングして再エンコードするのではなく、潜在変数を直接キャッシュすることで、計算コストとメモリ消費を大幅に削減した。 |
| 先行研究と比べてどこがすごい？ | 従来のRGBキャッシュ手法に比べ、エンドツーエンドの生成速度が最大10.57倍高速化し、GPUメモリ消費を最大55倍削減した。また、VAEの再エンコード過程で生じる情報損失やアーティファクトを排除し、より高精度な幾何学的整合性を実現している。 |
| 技術や手法のキモはどこ？ | 深度ガイド付きバックプロジェクションにより、潜在変数のトークンを3Dキャッシュに直接保存する点。また、キャッシュの読み出しを「潜在解像度でのプロジェクション」のみで行うことで、画素空間での複雑な処理（レンダリングと再エンコードのループ）を回避した点。 |
| どうやって有効だと検証した？ | 「WorldScore」および「RealEstate10K」ベンチマークを用いて、既存の3D認識ビデオ生成手法やRGBメモリ手法と比較評価した。特に、カメラが元の位置に戻る閉ループ評価プロトコルにおいて、優れた幾何学的一貫性と映像品質を示した。 |
| 議論はある？ | 動的な物体や空の領域は、幾何学的な信頼性が低いためキャッシュから除外するフィルターを採用しており、激しく動く物体の一貫した状態保持には限界がある。今後は動的なコンテンツを長期的に保持する手法が課題となる。 |
