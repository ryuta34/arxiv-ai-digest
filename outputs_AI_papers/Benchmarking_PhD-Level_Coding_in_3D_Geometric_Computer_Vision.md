# Benchmarking PhD-Level Coding in 3D Geometric Computer Vision

| 項目 | 内容 |
|---|---|
| どんなもの？ | 3Dコンピュータビジョン（3D-CV）の研究コード実装能力を評価するための、初となるPhDレベルのベンチマーク「GeoCodeBench」を提案した。最新のトップ論文から抽出した100個の複雑な課題と、自動生成された厳格なユニットテストを用いて、LLMのコード生成能力を評価する。 |
| 先行研究と比べてどこがすごい？ | 従来のコーディングベンチマークが汎用的なプログラミングや、単なる論文の再現に留まっていたのに対し、GeoCodeBenchは3D幾何学特有の数学的な正確さ、物理的根拠、および複雑なアルゴリズムの論理構成を必要とする課題に特化している点。 |
| 技術や手法のキモはどこ？ | 専門家による選別プロセスと自動化パイプラインを組み合わせ、実世界の研究論文から「埋め込み可能な関数」を抽出し、エッジケースを含む高難度な自動生成ユニットテストを構築した点。また、タスクを「汎用3D能力」と「研究能力」の2階層で定義した。 |
| どうやって有効だと検証した？ | GPT-5やClaude-Sonnet-4.5など、主要な8つのLLMを対象にベンチマークを実施。ベストモデルのGPT-5でさえ合格率が36.6%に留まるという結果から、現在のLLMが3D科学技術計算において抱える能力の限界を定量的に示した。 |
| 議論はある？ | LLMが「もっともらしいが誤った実装」を行う傾向があることや、文脈（論文の内容）が長いほどかえって推論能力が低下する場合があるなど、長文科学理解における課題を指摘。また、数学的に同値だが異なる実装を行う「創造的正確性」についても言及している。 |
