# JanusMesh: Fast and Zero-Shot 3D Visual Illusion Generation via Cross-Space Denoising

| 項目 | 内容 |
|---|---|
| どんなもの？ | 異なる視点から全く異なる物体として認識される「3D視覚イリュージョン」を、ゼロショットで高速に生成するフレームワーク「JanusMesh」。既存の最適化ベースの手法（約40分）とは異なり、わずか3〜5分で高品質かつ幾何学的に整合性の取れた3Dメッシュを生成する。 |
| 先行研究と比べてどこがすごい？ | 最適化による長い処理時間を必要とせず、学習不要で高速に生成可能。また、直接連結手法に見られるような継ぎ目や背面からのセマンティック漏洩（不自然な見た目）を、SDFベースの融合で完全に解消した。 |
| 技術や手法のキモはどこ？ | 2段階構成：第1段階は「クロス空間デュアルブランチ・デノイジング」により、CLIP誘導の向き合わせとSDFブレンディングを用いて複数の3D潜在表現を幾何学的に融合する。第2段階は「ビュー条件付きテクスチャ合成」で、各視点に応じたプロンプトを投影・集約して高精細な色付けを行う。 |
| どうやって有効だと検証した？ | 60個の多様なプロンプトペアを用いて、CLIP類似度、GPT-4.1-miniによるセマンティック認識精度、FID/KIDによる視覚的リアリズム、物体検出スコア、境界線の滑らかさ（Impact Factor）を評価。また、50名を対象としたユーザースタディで定性的評価を実施。 |
| 議論はある？ | 特定の物体カテゴリ（ブタやコウモリなど）では生成に失敗するケースがある。また、3オブジェクトの生成においては、3つのシルエットを平均化することで形状が曖昧になるため、自動的な向き合わせが課題として残る。 |
