# Action Images: End-to-End Policy Learning via Multiview Video Generation

| 項目 | 内容 |
|---|---|
| どんなもの？ | 7自由度のロボット操作を「マルチビュー動画」として生成することで、ロボットの動作を動画生成モデルの出力として定義する新しい学習フレームワークです。特定の行動モジュールを介さず、動画生成のバックボーン自体がゼロショットの政策決定（ポリシー）として機能します。 |
| 先行研究と比べてどこがすごい？ | 従来手法が低次元の数値データや非空間的な行動表現を用いていたのに対し、画素ベースの「アクション画像」を用いることで動画モデルの事前知識を最大限に活用できます。これにより、視点・環境の変化に対して高い汎化性能とゼロショットでの高い成功率を達成しました。 |
| 技術や手法のキモはどこ？ | ロボットの7自由度操作を、3つの3D点（位置、法線、上方向）に変換し、これを2D画素上のRGBガウスヒートマップとして描写する「Action as Images」という表現形式です。これにより、行動と視覚情報を完全に共通のビデオ空間で処理可能にしました。 |
| どうやって有効だと検証した？ | RLBenchおよび実世界ロボット（xArm）環境において、ゼロショットでのタスク成功率を計測。また、動画と行動の同時生成、行動条件付き動画生成、動画からの行動推定（ラベリング）といった複数タスクで従来の世界モデルを上回る性能を示しました。 |
| 議論はある？ | 現在はオープンループの推論に留まっており、クローズドループ制御（リアルタイムの修正）には未対応です。今後は推論の高速化と、リアルタイムのフィードバックループへの統合が課題として挙げられています。 |
