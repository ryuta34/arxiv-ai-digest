# The Optimal Sample Complexity of Multiclass and List Learning

| 項目 | 内容 |
|---|---|
| どんなもの？ | マルチクラス学習およびリスト学習における、DS次元を用いた最適サンプル複雑度を導出した理論論文。DanielyとShalev-Shwartz (2014) が長年提示していた予測を証明し、サンプル複雑度における $\sqrt{d_{DS}}$ のギャップを解消した。 |
| 先行研究と比べてどこがすごい？ | 従来はマルチクラス学習のサンプル複雑度に $d_{DS}^{1.5}$ の項が残るという理論的なギャップが存在したが、本研究はそれを $d_{DS}$ に改善し、最適であることを証明した。これにより、二値分類におけるVC次元と同様のクリーンな特徴付けがマルチクラス学習においても確立された。 |
| 技術や手法のキモはどこ？ | Hanneke et al. (2026) による多クラス仮説クラスの代数的な特徴付けを活用し、仮説クラスの「最大超グラフ密度」がDS次元によって上界されることを示した点。これにより、サンプル複雑度から余分な多項式因子を排除することに成功した。 |
| どうやって有効だと検証した？ | 定理1として、任意の整数 $\ell \ge 1$ に対して $\lceil\mu_H^\ell(n)\rceil \le d_{DS}^\ell$ が成り立つことを代数的に証明した。これに基づき、マルチクラス学習およびリスト学習におけるサンプル複雑度の上界を導出し、既存の下界と一致させることで最適性を検証した。 |
| 議論はある？ | サンプル複雑度のリストサイズ $\ell$ への依存性において、まだ $\ell$ と $1/\ell$ の間にギャップが残されている。また、アグノスティックな設定において $d_{Nat}/\epsilon^2$ の項が本当に必要かどうかは未解決であり、今後の課題としている。 |
