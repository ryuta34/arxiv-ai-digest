# RoboTTT: Context Scaling for Robot Policies

| 項目 | 内容 |
|---|---|
| どんなもの？ | ロボットの視覚運動ポリシーにおいて、コンテキスト長を8Kタイムステップまで拡張する「RoboTTT」を提案した論文。テスト時学習（TTT）をロボット基盤モデルに統合することで、推論の遅延を増やすことなく、長時間の複雑なタスクやワンショット模倣を可能にする手法。 |
| 先行研究と比べてどこがすごい？ | 従来のロボット基盤モデルは短時間の履歴しか扱えず、長時間の推論は限定的だった。本手法はTTTにより推論コストを一定に保ちつつコンテキストを3桁向上させ、5分間に及ぶ10段階のタスクを成功させるなど、長期間のタスク遂行能力を大幅に高めた点。 |
| 技術や手法のキモはどこ？ | モデルの再帰状態として「高速ウェイト（Fast Weights）」を採用し、テスト時に勾配降下法で動的に更新する点。また、学習の安定化のために「シーケンス行動強制（Sequence Action Forcing）」を用い、メモリを効率化するために「切断された時間逆伝播（TBPTT）」を採用した点。 |
| どうやって有効だと検証した？ | 3つの長距離タスク（Pup Go Car、Circuit、Gear Bot）で評価。単一ステップのベースラインと比較してタスク完了スコアを87%向上させたほか、ワンショット模倣能力や外部摂動に対する頑健性を実機実験で確認した。 |
| 議論はある？ | コンテキスト長が長くなると学習コストが増加する。また、あらゆる故障モードに対応できるわけではなく、今後は強化学習と組み合わせて成功率を直接最適化することが次のステップとなる。 |
