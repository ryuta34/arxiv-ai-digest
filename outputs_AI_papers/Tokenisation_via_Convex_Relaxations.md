# Tokenisation via Convex Relaxations

| 項目 | 内容 |
|---|---|
| どんなもの？ | 従来のBPEのような貪欲法に頼るトークナイザーとは異なり、線形計画法（LP）を用いて大域的に最適なトークナイザーを近似する新しい手法「ConvexTok」を提案した論文。最適化問題としてのトークナイズ構築を凸緩和することで、効率的かつ高品質なトークナイザーを実現している。 |
| 先行研究と比べてどこがすごい？ | BPEが局所的な最適化しか行わないのに対し、本手法は問題全体を考慮した大域的最適化に近いアプローチが可能である点。また、最適解からの距離（近似度）を数学的に証明・認証できるため、トークナイザーがどの程度最適に近いかを定量的に評価できる。 |
| 技術や手法のキモはどこ？ | トークナイズの問題をグラフ上の最短経路問題として定式化し、それを整数計画問題（IP）に変換した後、連続変数へと緩和した線形計画問題（LP）を解く点。得られた解に対し、決定論的またはバイアスをかけた手法で丸めを行うことで、離散的なトークン辞書を構築する。 |
| どうやって有効だと検証した？ | ClimbMix400Bデータセットを用いて学習し、BPEをベースラインとして比較評価した。Intrinsic metrics（圧縮率、語彙活用率など）での評価に加え、GPTスタイルのモデルにおける検証用BpB（bits-per-byte）やダウンストリームタスク（COREベンチマーク）での性能を広範に検証した。 |
| 議論はある？ | 計算コストはBPEより高い。ダウンストリームタスクの性能改善は一貫しているわけではなく、BPEと競合するレベルである。現在は圧縮の最適化に焦点を当てているため、今後は他の目的関数への拡張や、前処理に依存しないアプローチとの組み合わせが課題となる。 |
| 次に読むべき論文は？ | [Kozma and Voderholzer (2024)](https://arxiv.org/abs/2411.08671) や [Schmidt et al. (2025)](https://arxiv.org/abs/2502.xxxx) など、トークナイザーの理論的分析や境界を突破する手法に関する文献。 |
