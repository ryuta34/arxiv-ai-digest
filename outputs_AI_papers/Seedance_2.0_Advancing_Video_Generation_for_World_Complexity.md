# Seedance 2.0: Advancing Video Generation for World Complexity

| 項目 | 内容 |
|---|---|
| どんなもの？ | ByteDance Seedチームが開発した、テキスト・画像・音声・ビデオの4つのモダリティを統合した高性能なビデオ生成モデル「Seedance 2.0」。現実世界の複雑な動作や物理法則の忠実な再現、高い制御性を実現し、プロフェッショナルな映像制作に対応する。 |
| 先行研究と比べてどこがすごい？ | 従来比で動作の安定性、指示追従性、映像の写実性が大幅に向上。特にマルチモーダルな参照入力（テキスト、画像、音声、ビデオ）に基づいた編集や、プロレベルのカメラワーク、BGMと連動した高忠実度なバイノーラル音声生成において、競合モデルを大きく上回る性能を達成している。 |
| 技術や手法のキモはどこ？ | 音声・ビデオを同時に生成する統合的な大規模アーキテクチャを採用した点。複雑な指示を理解し、キャラクターの整合性を保持する推論能力と、現実世界の物理法則を遵守するための高度なモーションモデリング技術が核心にある。 |
| どうやって有効だと検証した？ | 新たな評価フレームワーク「SeedVideoBench 2.0」を構築し、客観的指標と専門家によるブラインドレビューを実施。また、Arena.AIの人間による嗜好性評価においてもText-to-VideoおよびImage-to-Videoの各タスクで1位を獲得し、定量的・定性的な優位性を証明した。 |
| 議論はある？ | まだ改善の余地があり、特に物理法則を極端に逸脱したケースでの動作の不自然さ、高周波の視覚的ノイズ、リップシンクの精度、複雑な多人数会話シーンでの音声整合性などに課題を残している。 |
