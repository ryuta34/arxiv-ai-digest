# The Key to Going Linear: Analysis-Driven Transformer Linearization

| 項目 | 内容 |
|---|---|
| どんなもの？ | 既存の学習済みTransformerを、事前学習なしで線形時間推論が可能なアーキテクチャに変換するポストホック線形化手法の分析。固定されたバックボーンに対して、線形な状態更新メカニズムがソフトマックス注意をどの程度近似できるかを理論的・実験的に解明した。 |
| 先行研究と比べてどこがすごい？ | 従来手法はLoRAや蒸留などの手法を混合していたため、線形化の本質的な性能が不明瞭だった。本研究ではバックボーンを完全に凍結した厳格な設定で比較し、デルタ則（Delta Rule）に基づくメカニズムがソフトマックスの幾何学的特性を最も忠実に再現することを発見した点。 |
| 技術や手法のキモはどこ？ | ソフトマックス注意が「キー依存のランク1の直交射影」として機能していることを理論的に導出し、この特性をネイティブに実装できるGated Delta Networks (GDN) が他手法（純粋なゲート付き累積）より優れていることを示した点。また、性能不足を補うためのシンク・トークンや短距離畳み込みなどの構造的介入を提案した。 |
| どうやって有効だと検証した？ | LLaMA 3.1およびQwen 3（最大32Bパラメータ）のモデルを使用し、DCLM-Eduデータセットで追加学習を行って検証。MMLUや長文コンテキスト推論（RULER）において、既存の線形化ベースラインを上回る性能を実証した。 |
| 議論はある？ | 理論的な導出には一部近似的な仮定が含まれており、層や極端に短いプレフィックスに対しては完全に一致しない場合がある。また、複雑な適応型キャッシュ手法と比較して、コンテンツに基づいた動的なトークン保持の仕組みは未実装である。 |
