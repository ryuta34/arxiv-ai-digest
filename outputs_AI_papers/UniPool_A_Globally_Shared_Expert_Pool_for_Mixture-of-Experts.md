# UniPool: A Globally Shared Expert Pool for Mixture-of-Experts

| 項目 | 内容 |
|---|---|
| どんなもの？ | 従来の混合エキスパート（MoE）モデルが層ごとにエキスパートを個別に所有する仕組みを改め、Transformer全体で単一の「グローバルに共有されたエキスパートプール」を利用する新しいアーキテクチャ。層間のエキスパートの冗長性を排除し、エキスパート容量をサブ線形にスケーリング可能にする手法。 |
| 先行研究と比べてどこがすごい？ | 従来手法では層ごとにエキスパートを固定するためパラメータ数が増大するが、本手法は共有プールによりパラメータ効率を大幅に向上させた。特に、より少ないエキスパート予算で従来モデルを上回る精度を達成し、モデルの深さに応じてエキスパート数を最適化できる点が優れている。 |
| 技術や手法のキモはどこ？ | 层ごとの独立した補助損失の代わりにプール全体で利用率を最適化する「プールレベルの補助損失」の導入と、入力規模に左右されず安定したスパースルーティングを実現する正規化ベースのルーティング手法「NormRouter」を組み合わせた点。 |
| どうやって有効だと検証した？ | 182Mから978Mまでの5つの異なるモデルスケールでLLaMAアーキテクチャをベースに30Bトークンの学習を行い、従来型のVanilla MoEと比較。検証損失、困惑度（Perplexity）、およびゼロショット評価指標（ARC, PIQA, HellaSwag等）を用いて性能向上を確認した。 |
| 議論はある？ | 実装上の課題として、層間統計の蓄積による計算オーバーヘッドのわずかな増加がある。また、現在評価されているのは1Bパラメータ未満の小規模モデルが中心であり、超大規模モデルでのスケーリングや学習効率については将来的な検証課題としている。 |
