# AI with Authority, from Application to Silicon

| 項目 | 内容 |
|---|---|
| どんなもの？ | 生成AIによる開発を形式手法と組み合わせることで、機械検証された証明やシステム設計を高速かつ安全に実現する「Salt法」を提案したケーススタディ。人間が介在せずAI艦隊がコードと証明を生成し、RISC-Vプロセッサのテープアウトまでを単独で達成した。 |
| 先行研究と比べてどこがすごい？ | 従来、人間にはコスト高だった機械検証が、AIの高速な証明生成と組み合わせることで、かえって生産性を高める必須のインフラへと役割を逆転させた点。1人で5週間という短期間で、アプリケーションからシリコンテープアウトまで一貫した検証済みスタックを構築した。 |
| 技術や手法のキモはどこ？ | AIに「実装・仕様・証明・テスト・証明書」の5点セットを生成させ、すべての数学的証明をLean 4カーネルで検証する体制。エラーを「append-onlyの台帳」に記録し、人間は「コードのレビュー」ではなく、人間言語による要求定義と、カーネルで保証された「証明書」の対話的検証にのみ注力する点。 |
| どうやって有効だと検証した？ | 37日間の連続稼働において2,087件のコミットを行い、そのすべてを機械検証した。RISC-Vプロセッサの設計において、902個のフリップフロップのうち約31.9%をカーネル検証済みアーティファクトから生成し、論理的整合性を実証した。 |
| 議論はある？ | 提案手法は特定の環境（専門家による運用とAIの高速生成）に依存しており、汎用的な労働市場への適応は不明。また、ハードウェア検証の一部でSATソルバを利用する非均質なリンクが存在し、純粋なカーネル検証の範囲には限界がある。 |
