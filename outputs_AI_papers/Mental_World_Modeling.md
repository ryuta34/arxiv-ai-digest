# Mental World Modeling

| 項目 | 内容 |
|---|---|
| どんなもの？ | 物理的な環境状態だけでなく、エージェントの信念、意図、感情、社会規範といった「メンタル状態」を明示的に組み込んだ「メンタル世界モデル（MWM）」という理論フレームワーク。エージェントが次にどのような行動をとるかを、単なる物理変化としてではなく、その背景にある心理的・社会的プロセスをシミュレーションすることで予測する。 |
| 先行研究と比べてどこがすごい？ | 従来のワールドモデルが物理的な対象の動きや空間構造の予測に終始していたのに対し、MWMは心理状態を変数としてシミュレーションに組み込む。これにより、なぜその行動をとったのかという理由（社会的意思決定）まで含めた説明可能かつ高い予測精度を実現した点。 |
| 技術や手法のキモはどこ？ | 状態を「物理状態（オブジェクトや環境）」と「メンタル状態（信念や意図など）」の結合したペアとして定義し、さらにターゲットの視点に基づいた「部分観測」と、行動に伴う「物理的・メンタルな遷移の同時シミュレーション」を行う点。また、これらの過程を可視化・検証可能にする実装「MENTIS」を提案した点。 |
| どうやって有効だと検証した？ | 「Menti-Bench」という448のタスクからなるベンチマークを作成し、8種類の現代的なLLMベースのワールドモデルを用いて実験。段階的にモデルの複雑さを増す「必然性ラダー」を用いて、メンタル状態の明示的なモデリングが予測精度向上に不可欠であることを証明した。 |
| 議論はある？ | 現在の実装は一段階の推論に留まっており、長期的な記憶や相互的な信頼関係の変化を扱うにはさらなる拡張が必要。また、メンタル状態の推論はあくまで仮説であり、不確実性や社会的バイアスの管理が今後の大きな課題である。 |
