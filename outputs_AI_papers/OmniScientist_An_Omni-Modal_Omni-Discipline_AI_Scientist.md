# OmniScientist: An Omni-Modal Omni-Discipline AI Scientist

| 項目 | 内容 |
|---|---|
| どんなもの？ | 科学研究の全ワークフロー（アイデア出しから実験、論文執筆まで）を自律的に行う、マルチモーダル対応のAI科学者「OmniScientist」。画像、信号、3Dデータなどの生の科学的エビデンスを直接知覚・分析できる点が最大の特徴。 |
| 先行研究と比べてどこがすごい？ | 従来のAI科学者はテキストやコード、要約されたデータしか扱えなかったが、本システムは生のマルチモーダルデータから直接知覚・分析を行う。これにより、人間が介在せずに、データに基づいた科学的発見をEnd-to-Endで自動生成できる。 |
| 技術や手法のキモはどこ？ | 知覚レイヤーと3つの自律エージェント（Ideation, Experiment, Writeup）に加え、コードベースの検証パイプラインを統合した点。特に、研究の進捗をコードで強制的に検証（再現性、統計的妥当性、HARKing防止）し、結果に基づかない主張を排除する堅牢な構造にある。 |
| どうやって有効だと検証した？ | 5分野、36の科学的実データケースを用いて検証。ブラインド比較テストでは、事前計算済みのスカラー特徴量のみを使用するモデルに対し、生の知覚情報を持つ本システムが85%のケースで勝利し、評価項目すべてで性能向上を達成した。 |
| 議論はある？ | 評価は特定のベンチマークセットに基づいている点。また、自律的な研究プロセスにおいて、モデルの推論バックボーンの性能が評価結果に直結するため、より高度な推論モデルへの依存や、計算コストの最適化が将来の課題。 |
