# OmniRobotHome: A Multi-Camera Platform for Real-Time Multiadic Human-Robot Interaction

| 項目 | 内容 |
|---|---|
| どんなもの？ | 48台のハードウェア同期RGBカメラと2台のロボットアームを統合し、実環境でのリアルタイムな3D知覚と協調動作を可能にする、ルームスケールの人ロボット共生プラットフォーム。人間とロボットが複雑に干渉し合う「マルチadic（多人・多ロボット）」な環境でのインタラクションを研究するためのAIテストベッド。 |
| 先行研究と比べてどこがすごい？ | 既存の多視点カメラシステムはオフライン処理が主であったが、本システムは広域かつオクルージョンに強い3D知覚をリアルタイムで実現した。これにより、ロボットが現在の人間や物体の状態に応答し、さらに長期的な行動記憶に基づく先回りした支援が可能となった点。 |
| 技術や手法のキモはどこ？ | 12の分散エッジノードで並列処理を行い、中央サーバーでRANSACを用いた3D関節再構築と物体の6Dポーズ推定を行うパイプライン。さらに、過去の人間行動の軌跡を蓄積する「行動記憶（Behavior Memory）」と、それをLLMやVLMと組み合わせた意図推定・安全制御の統合。 |
| どうやって有効だと検証した？ | キッチン整理というシナリオを用い、安全性の観点（衝突数やサイクルタイム）と、先回りした支援（物体配置予測の正確性）について、ベースライン手法（非認識、静的半径など）との比較実験を行い、性能向上を実証した。また、キャリブレーション精度やカメラ数に関する消去実験も実施。 |
| 議論はある？ | 現在は固定ベースのロボットアームを用いた単一の実験室環境での評価にとどまる。今後はモバイルロボットへの展開、多様なレイアウトへの汎化、そして本プラットフォームで得られる大規模かつ高品質なマルチadicデータの公開が課題。 |
