# Long-WAM: Scaling the Context of World-Action Models

| 項目 | 内容 |
|---|---|
| どんなもの？ | リアルタイム制御におけるロボットの視覚履歴（コンテキスト）の活用をスケールさせるためのモデル・システムフレームワーク「Long-WAM」。長期の視覚コンテキストを効果的に処理し、予測ベースの制御により、動的なマニピュレーションや長期のタスク実行を高い成功率で実現する。 |
| 先行研究と比べてどこがすごい？ | 単なる履歴へのアクセスではなく、ビデオ生成モデルの事前学習における「自己回帰（AR）的な因果予測構造」を維持したまま行動モデルに適応させることで、コンテキストの増大が直接的に制御精度の向上につながる点。また、リアルタイム制約下で予測と実行を両立させる非同期実行基盤と、エッジデバイス向けに最適化された推論エンジンを備えている点。 |
| 技術や手法のキモはどこ？ | ロボットおよび一人称視点動画による大規模な自己回帰（AR）ビデオ事前学習と、その因果構造を保ったままのアクション適応。さらに、推論の遅延を抑えるストリーミングVAE、CUDA Graphを用いた最適化、およびデバイスごとのカーネルチューニングにより、長文脈を扱いながらもRTX 5090等で実時間動作を実現した点。 |
| どうやって有効だと検証した？ | RoboCasa GR-1、LIBERO-Long、RoboTwin 2.0、DOMINOといったベンチマークでの定量的評価に加え、実機Unitree G1を用いた動的なカップ積載タスク、およびYAMロボットでの長期タスク実行にて検証。コンテキストの長さと成功率の関係、および推論遅延のトレードオフを詳細に分析した。 |
| 議論はある？ | 38.4秒以上の非常に長いコンテキストでは、データセットのパディング（無効データ）が増えるため性能が低下する可能性を指摘。また、タスクに応じて最適なコンテキスト長が異なる可能性や、今後は状況に応じて動的にウィンドウサイズを調整するモデルの必要性に言及している。 |
