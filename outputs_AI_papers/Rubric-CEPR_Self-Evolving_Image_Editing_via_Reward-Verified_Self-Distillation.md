# Rubric-CEPR: Self-Evolving Image Editing via Reward-Verified Self-Distillation

| 項目 | 内容 |
|---|---|
| どんなもの？ | 画像編集モデルが、自身の生成した画像の中から「指示通りに編集できたもの」を自律的に検証・選別し、そのデータで自身を再学習することで性能を向上させる自己進化フレームワーク「Rubric-CEPR」です。人間による正解データや外部の報酬モデルを一切使わずに、モデル自身の知識のみで画像編集能力を強化します。 |
| 先行研究と比べてどこがすごい？ | 従来の自己学習手法は、単なるスカラー報酬に基づくことが多く、不完全な編集結果を誤って学習するリスクがありました。本手法は、編集が実現されたか、古い状態が削除されたか、内容が保持されているかといった「構造化されたルーブリック（評価基準）」と「非補償型の選別ゲート」を用いることで、 plausibility（らしさ）ではなく「正確な編集」を確実に選別・学習できる点に優位性があります。 |
| 技術や手法のキモはどこ？ | Planner（編集指示と構造化仕様の生成）、Editor（画像編集）、Critic（固定された自己検証器）の3者による「提案→編集→検証→蒸留」のループです。特に、編集の各側面を個別にスコア化し、どれか一つでも不適合があれば即座に棄却する非補償型の厳格なゲート機構が、質の高いデータセット構築の核心です。 |
| どうやって有効だと検証した？ | ImgEdit、GEdit-Bench、Complex-Editといった標準的な画像編集ベンチマークを用いて評価しました。ベースモデル（Qwen-Image-Edit-2509等）と比較し、特に弱点であった「物体抽出（Object Isolation）」において最大24.9%の大幅な性能向上を確認し、他のベンチマークへの汎用的な転移も実証しました。 |
| 議論はある？ | 自己進化には、モデルの既存のサンプリング分布に成功事例が含まれていることが前提となります。また、内部的な検証手法の限界から、複雑な調整編集などの一部タスクでは改善幅が限定的である可能性を指摘しています。今後はより高度な内部検証手法の開発や、多段階の自己進化プロセスの検証が課題です。 |
