# Context-Aware RL for Agentic and Multimodal LLMs

| 項目 | 内容 |
|---|---|
| どんなもの？ | 長期的な推論やマルチモーダルタスクにおいて、モデルが文脈中の微細な情報を見落とす「文脈非認識（context unawareness）」という課題を解決するための手法。強化学習（RL）の過程で、与えられた回答を裏付ける文脈を正しく選択するようにモデルを訓練する新しい手法「CONTEXTRL」を提案している。 |
| 先行研究と比べてどこがすごい？ | 最終的な回答の正誤のみを報酬とする従来のRL手法とは異なり、文脈の重要性を明示的に学習させる補助的な目的関数を導入している。データ拡張を行う既存手法と異なり、本手法はモデルの性能を低下させることなく、エージェントタスクやマルチモーダルタスクの両方で一貫した性能向上を実現している点。 |
| 技術や手法のキモはどこ？ | クエリ、回答、および「回答を支持する文脈（肯定例）」と「回答を支持しない類似した文脈（否定例）」のペアを用意し、モデルが肯定例を選択するように強化学習の目的関数にコントラスティブな補助損失（context-awareness loss）を追加した点。 |
| どうやって有効だと検証した？ | エージェント向けに1k件、マルチモーダル向けに7k件のコントラスティブな文脈ペアを構築し、5つの長期エージェントベンチマークと12のマルチモーダルベンチマークで評価。RLベースラインやデータ拡張ベースラインと比較し、すべてのタスクで一貫した性能向上を確認した。 |
| 議論はある？ | 実験モデルのパラメータ数が10B未満に限定されており、より大規模なモデル（30B以上）での検証が今後の課題。また、評価したモデルの多くがQwenファミリーに偏っているため、他のモデル系列への汎用性検証が必要であると述べている。 |
