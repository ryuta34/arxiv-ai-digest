# Data Scarcity and Model Sparsity: Mixtures-of-Experts Overfit More to Repeated Data

| 項目 | 内容 |
|---|---|
| どんなもの？ | 言語モデルの訓練において学習データが枯渇し、データのリピート（再利用）が一般的になる中で、Mixture-of-Experts (MoE) モデルがデータのリピートに対して密なモデルよりも過学習しやすく、性能が急速に低下することを明らかにしました。データのリピート率とモデルのアーキテクチャ（スパース性など）が過学習に与える相互作用を詳細に分析した研究です。 |
| 先行研究と比べてどこがすごい？ | 密なモデルについては先行研究がありますが、近年主流のスパースなMoEモデルにおけるデータリピートの悪影響を包括的に調査しました。全パラメータ数とアクティブパラメータ数の分離、専門家（エキスパート）の数や粒度の変動、複数のデータドメインや混合比率などの網羅的なグリッドスイープを通じて、過学習の機序を解明しました。 |
| 技術や手法のキモはどこ？ | MoEモデルにおいて、学習の初期段階でルーティングが「固定化（ossification）」し、各エキスパートが特定のトークンサブセットのみを繰り返し処理することで過学習が促進されるという機序を特定しました。その対策として、Dropoutや出力マスキングといった手法が、パラメータの過度な専門化を防ぎ過学習を軽減できることを示しました。 |
| どうやって有効だと検証した？ | 80Mから1Bのアクティブパラメータを持つモデルを用い、データリピート率（R=1〜1024）を変えた大規模なグリッドスイープを実施しました。バリデーションロス、トレーニングロスの推移、エキスパートの活性化パターン、専門家ノックアウトによる性能影響評価などを通じて、アーキテクチャやドメインごとの過学習挙動を検証しました。 |
| 議論はある？ | 提案された正則化手法（Dropout等）は過学習を緩和するものの、ユニークなデータのみで学習した場合の性能には完全には及ばないという限界があります。また、ルーティングの固定化を防ぐためのより根本的なアーキテクチャの改善や、セマンティックな類似性に基づいたデータ混合による緩和策が将来の重要な研究課題として挙げられています。 |
