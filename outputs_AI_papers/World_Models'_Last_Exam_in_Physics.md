# World Models' Last Exam in Physics

| 項目 | 内容 |
|---|---|
| どんなもの？ | 動画生成モデルの物理的な一貫性を評価するための測定ベースのベンチマーク「World Models’ Last Exam in Physics」の提案。力学、光学、流体力学など9つの物理領域にわたる40の制御されたタスクを用いて、モデルの物理的妥当性を定量的に測定する。 |
| 先行研究と比べてどこがすごい？ | VLM（視覚言語モデル）の主観判断や単なる参照ビデオとの比較に頼らず、タスク固有の物理測定指標を用いることで、より客観的で解釈可能な評価を実現した。また、特定の物理領域に限定せず、幅広い現象をカバーしている。 |
| 技術や手法のキモはどこ？ | 物理法則を満たすべき「観察可能な関係性（空間・時間・時空間）」を数式化し、追跡やセグメンテーション等のツールを用いて動画から直接物理量を抽出するパイプラインを構築した点。また、自動評価において信頼性が低い動画を事前に除外する「自動一貫性ゲート（C >= 80）」を採用している。 |
| どうやって有効だと検証した？ | 8つの主要な動画生成モデル（CogVideoX、HunyuanVideo、Seedance等）を用いて計1,280本の動画を評価。さらに、合成された正解動画を用いて評価手法の妥当性を確認し、人手による評価との相関を計算することで、従来手法（Direct VLM）よりも人間に近い評価ができることを示した。 |
| 議論はある？ | 現在の評価は、物体が視覚的に認識可能で、かつ抽出ツールが対応可能なシーンに限られるという限界がある。また、複雑なシーンにおける物理法則の再現には依然として課題がある。 |
